# 逻辑审计（通用版）

- [ ] 主角唯一，第 1 幕和结尾同一个人
- [ ] 主题一句话可复述，第 1 幕立住、结尾收住
- [ ] 开头抓人：最抓眼球的画面在前面，文字稿写清第几秒出现什么
- [ ] 旁人反应三段式：每个包袱/转折分三段写（问题 → 主角怎么解决 → 旁人什么反应），反应有先后，绝不同时做同一个动作
- [ ] 现实追问：每个转折都问过为什么会这样、东西从哪来、够得着吗、现实里真会这样吗
- [ ] AI 弱点避让：人物交叉、手拿小东西、文字、镜子与倒影、左右不对称特征、一镜内换光、一人连做三个动作、俯拍看不到脸、配角太多，写故事时已避开（避不开的写清改法）
- [ ] 结构默认片段式：连贯式只在用户点名时用
- [ ] 物品全程状态连续：位置和状态一致，或有画面动作解释变化（具体怕项只按本集锁定表查）
- [ ] 因果连续，无“刚好出现”的人
- [ ] 反转有伏笔（伏笔位置：__，payoff：结尾）
- [ ] 出场按需，不硬凑全员
- [ ] 场景在锁定场景内，路线不瞬移
- [ ] 生成画面内文字的语言 = 目标语言（中国场景一律汉字，不许英文字母），无已知 IP 造型，无品牌风格词
- [ ] 外人复述测试通过：谁、干什么、出什么问题、怎么反转
