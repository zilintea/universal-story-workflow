# 分镜转场一致性审计（v1.4 新增，逐对核对）

每对相邻分镜都要填一行，不填即不通过：

| 转场 | 上一镜尾帧 | 下一镜首帧 | 人物 | 物品 | 场景 | 时间 | 转场类型 | 通过？ |
|---|---|---|---|---|---|---|---|---|
| 1→2 | | | 一致/变化原因 | 一致/变化原因 | 一致/变化原因 | 一致 | 硬切/动作匹配/遮挡/叠化 | |
| 2→3 | | | | | | | | |

硬项：
- [ ] 首尾帧衔接：下一镜首帧 = 上一镜尾帧，逐字复用（见 scripts/check_shotcard.py）
- [ ] 镜头卡完整：每镜 14 个字段齐全（景别/机位/运镜/构图/光线/色彩/动作起—中—止/环境动态/首尾帧/情绪）
- [ ] 180 度轴线：同一场景内 camera_side 不变
- [ ] 30 度规则：同一主体连续两镜，角度变化 ≥30 度或景别明显变化
- [ ] 动作匹配：动作不中断、不重复、不倒退
- [ ] 视线匹配：看向左，下一镜的东西在左
- [ ] 物品连续：位置和状态一致，或有画面动作解释变化
- [ ] 场景连续：固定元素、主色调、光线一致，或转场本身是场景切换
- [ ] 景别节奏：每镜 ≥2 秒，连续 3 镜不为同一景别
- [ ] 文化锚点（v2.7，有文化属性的 IP 必查）：文字稿“文化锚点”一节五类齐全（服饰/食物/器物/地貌/色彩），每类写具体物，不含空词（“中国元素”“西方元素”“中国风”“东方元素”单独出现即不通过）
- [ ] 文化锚点进提示词：每段视频提示词逐字复用了文化锚点（脚本 scripts/apply_culture.py 输出可验）
- [ ] 画面内文字（v3.3）：每镜的画面内文字（牌匾、招牌、旗帜、碑刻）的语言 = 目标语言；中国场景一律汉字，不许出现英文字母，其他国家跟其语言；需要出现的字（标题、字幕）走后期，不进提示词（借鉴 film-studio-skills：画面内文字单独列任务清单，不混进生成提示词）
- [ ] 国家形象标志（v3.0）：每镜画面内无国旗、国徽、旗帜等国家形象标志；制服只写颜色和款式，不写徽章图案；招牌只写颜色和形状，不写旗帜；广场不写升旗、阅兵类场面（脚本 scripts/check_story.py 扫描文字稿，见 docs/CHARACTER_DEFAULTS.md）
