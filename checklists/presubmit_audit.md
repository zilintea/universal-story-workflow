# 提交前新视角审计（v3.7 新增）

> 生成视频要花钱，提交之前必须过这一关。审计者是 fresh 视角：只读材料，不改文件，
> 不看任何结论，只按下面逐项核对，最后只写“通过”或“不通过”。
> 不通过就逐条列出要改什么，改完再审；通过了才报价、才提交。

## 材料（只给这些，不给结论）
- 本镜的七段式视频提示词（templates/video_prompt_7seg.md 格式）
- 首帧、尾帧、设定图、分镜表、配色规则

## 核对项（放大看图，逐项打勾）
- [ ] 主画布传了吗？第一张参考图是主画布当前版吗？版本号与文字稿一致吗？
- [ ] 生长主体（v3.13）：第一张参考图改传当前阶段格裁剪（或该阶段物品画布），不是整张主画布；提示词只写本阶段 DNA，不写其他阶段的形态。
- [ ] 过程镜（v3.14）：参考图传旧阶段格裁剪 + 新阶段格裁剪两张（先后顺序 = 转变顺序）；提示词写清起止两态（首帧旧阶段末态、尾帧新阶段初态）；阶段锁定写“不演进到下一阶段的完成态/展开态”，不写“不演进到下一阶段”。
- [ ] 历史过程（v3.15）：每段是缩时过程镜，提示词写清起止两态（首帧地基、尾帧成墙）；工期/工序已自查，不确定处写“未确认”，不编造；时间跳跃线按年写，不是一天。
- [ ] 物品画布传了吗？出场物品的物品 DNA 与非此物清单逐字写进提示词了吗？物品特写时传了主画布上该物品格的裁剪图吗？
- [ ] 提示词的每句话和两张图对得上吗？（位置、左右、颜色、人数、道具数量、衣服、表情）
- [ ] 人数写死了吗？“画面里一直只有 N 人，逐帧数人”写了吗？远处小人、半个头也算多余人。
- [ ] 物品数量与形状写死了吗？（例如“只有 3 只盏，茶杯大小，非碗”；形状、尺寸与手的比例与物品画布一致吗？）
- [ ] 两张图的机位、大小、背景一致吗？首尾帧尺寸一致、宽高比正确吗？
- [ ] 和设定图、配色规则、前后镜头对得上吗？（角色 DNA 逐字复用、固定道具位置左右没反）
- [ ] 动作现实吗？每个动作的原因有了吗？手放在哪？（见 docs/MODEL_ERROR_TABLE.md）
- [ ] 动作要用的东西，首帧里有吗？雨、帽子、纹身这类东西，首尾帧都有吗？
- [ ] 旁人反应有先后吗？首帧里几个人是不是摆了同一个姿势？
- [ ] 模型可能哪里出错？（同时动作、凭空出现、长脸、走反方向、歧义词、数量变化）
- [ ] 运镜多样性（v3.19）：每镜机位/运镜出自 `docs/SHOT_LANGUAGE.md` 全表，按场景需求调用；60 秒片同一运镜最多 2 次，特写 + 推近组合全片最多 2 镜；全片运镜清单已列出，无超限。
- [ ] 节奏（v3.20）：每镜 tempo 已填（快/中/慢）；打斗/动作场面快镜占比 ≥ 一半，快镜 beats 2–3 已写；慢动作 SLOWMO 全片 ≤1 次，不连续两镜，快 tempo 的镜没用 SLOWMO。
- [ ] 动作版模板（v3.20）：快节奏段用动作版——开场即在动中、不冻帧，尾帧是动作进行中的一帧；速度词（骤然、猛地、瞬间）已写进逐秒动作；没把用户的快词翻成“平静地、缓缓地”。
- [ ] 动作点验收（v3.20）：快镜的首/中/尾三帧各不相同，三帧几乎一样 = 静态 = 不通过；每个动作点（出剑、格挡、反击、扑击）在抽帧里看得见，没打出来 = 不通过，只重做该段。
- [ ] 剧本先于画布（v3.18）：人物、关键物品、场景是从剧本里抽的，不是先锁死的；剧本里有的人物、关键物品、场景都有图版，图版上没有剧本外的人物、物品、场景。
- [ ] 拍摄剧本（v3.17）：剧本已按 `docs/SCREENPLAY_FORMAT.md` 输出（场次标题、每镜机位、首帧尾帧、转场标明、附录锁表）；用户审的是剧本，不是散文件。
- [ ] 无限画布（v3.16）：画布已在视频生成前输出，用户已在画布上确认本段节点（状态“已确认”）；待调整的节点不生成、不烧积分。
- [ ] 提示词默认禁令（v3.16）：没加用户没提过的 blanket 禁止（例如“无血腥”“画面里没有任何文字”）；血腥与画面内文字按用户本项目的要求走，儿童片按 `docs/CHILD_SAFETY.md`。
- [ ] 时空切片（v3.30）：10 秒一段切成 5 个节点，每 2 秒一节点，每节点都绑定了【画面 + 动作 + 运镜】吗？没有一段笼统的长描述吗？节点 1 的画面等于首帧、节点 5 的画面等于尾帧吗？切镜点（5 秒处）写明在哪个节点的哪一秒切了吗？连续段的节点 1 画面等于上一段尾帧吗？
- [ ] 物理参数（v3.30）：提示词里没有“很顺滑”“很震撼”“很美”这类情绪形容词吗？运动、光、形变、对焦四类物理参数至少各写了一条吗？（对照 templates/video_prompt_7seg.md 物理参数词库）
- [ ] 质感反差（v3.30，微缩 / 微距 / 比例反差场景才查）：对撞的两组质感、焦点锁定（微距移轴 + 极浅景深）、视觉闭环（玻璃罐封盖等）三要素齐全吗？普通场景（无比例反差）跳过此项，不硬套。
- [ ] 物理参数按内容选（v3.31）：先定了本段的内容类型吗？参数是从 docs/PHYSICAL_PARAMETERS.md 对应类型里挑的吗？有没有跨类型硬套（例如儿童故事用冷调侧光、产品用尘土飞扬）？运动、光、形变、对焦四类至少各写了一条吗？每个参数绑定了具体对象吗？
- [ ] 特写开场第一参考图（v3.31）：特写 / 微距的切镜开场，第一参考图是目标局部的裁剪图吗？整张主画布只作第二参考图吗？提示词写死了特写范围（“占满整帧、不拉回全景”）吗？普通开场（非特写）跳过此项。
- [ ] 用户的要求清单有没有漏？（对照用户原话逐条查，包括画幅、时长、语言、风格、禁项）

## 结论
- 只写“通过”或“不通过”，不写“差不多”“基本可以”。
- 不通过：逐条列出要改什么（哪句话、哪张图、哪里不对），不改文件。
