# 提交前新视角审计（v3.7 新增）

> 生成视频要花钱，提交之前必须过这一关。审计者是 fresh 视角：只读材料，不改文件，
> 不看任何结论，只按下面逐项核对，最后只写“通过”或“不通过”。
> 不通过就逐条列出要改什么，改完再审；通过了才报价、才提交。

## 材料（只给这些，不给结论）
- 本镜的七段式视频提示词（templates/video_prompt_7seg.md 格式）
- 首帧、尾帧、设定图、分镜表、配色规则

## 核对项（放大看图，逐项打勾）
- [ ] 提示词的每句话和两张图对得上吗？（位置、左右、颜色、人数、道具数量、衣服、表情）
- [ ] 两张图的机位、大小、背景一致吗？首尾帧尺寸一致、宽高比正确吗？
- [ ] 和设定图、配色规则、前后镜头对得上吗？（角色 DNA 逐字复用、固定道具位置左右没反）
- [ ] 动作现实吗？每个动作的原因有了吗？手放在哪？（见 docs/MODEL_ERROR_TABLE.md）
- [ ] 动作要用的东西，首帧里有吗？雨、帽子、纹身这类东西，首尾帧都有吗？
- [ ] 旁人反应有先后吗？首帧里几个人是不是摆了同一个姿势？
- [ ] 模型可能哪里出错？（同时动作、凭空出现、长脸、走反方向、歧义词、数量变化）
- [ ] 镜头卡 16 个字段齐全吗？moving（这镜什么在动）和 move_reason（运镜为什么动）填了吗？
- [ ] 用户的要求清单有没有漏？（对照用户原话逐条查，包括画幅、时长、语言、风格、禁项）

## 结论
- 只写“通过”或“不通过”，不写“差不多”“基本可以”。
- 不通过：逐条列出要改什么（哪句话、哪张图、哪里不对），不改文件。
