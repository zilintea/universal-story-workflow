# 语言审计（通用模式也查语言一致性，教学模式另查下半部分，见 docs/TEACHING_MODE.md）

## 通用核对（v2.8，见 docs/LANGUAGE_LOCK.md）

- [ ] 目标语言 = 用户那句话的语言，写在文字稿“语言锁定”一节，不默认英语
- [ ] 目标语言默认值（v3.0）：人物类剧集用户没特别指定时，目标语言一律中文；只在用户明确指定其他语言（如“用英语讲”）或非中国背景（如“美国故事”）时才改
- [ ] 对话、旁白、字幕与目标语言一致（脚本 scripts/check_story.py 输出：zh 无拉丁字母单词，en 无 CJK 字符）
- [ ] 多语言对话（v3.2，见 docs/LANGUAGE_LOCK.md）：旁白始终用目标语言；对话按说话人走，`character_languages` 字段写每人的语言（默认目标语言），字幕用目标语言；脚本按每句的有效语言查一致性，`character_languages` 的值须有语言档案
- [ ] 视频提示词里的对话/旁白/字幕文本用目标语言写，不翻译；画面描述用英文写

## 教学模式核对（教学模式时才用，通用模式时不查）

- [ ] 目标语言、难度在文字开头明示
- [ ] 关键词汇 ≤5 个，每个在对话或旁白里出现 ≥3 次，且至少 1 次在笑点里
- [ ] 句型 ≤2 个，每个在剧情里自然重复 ≥2 次，且第二次更有用
- [ ] 对话每句短（初级：≤10 字/词），无一次说两句长句的角色
- [ ] 旁白与对话不重复同一句话：旁白讲背景和心情，对话讲能跟读的句子
- [ ] 互动点 ≥1 处（停顿提问 / 跟读 / 选择），写在剧本里
- [ ] 无说教总结句，无字幕堆砌生词
- [ ] 词汇表、句型表、复习问题齐全，答案在故事里
- [ ] 娱乐比学习：笑点、反转、画面占主导，学习藏在剧情里
