# 镜头卡审计（v1.9 新增，见 docs/SHOT_LANGUAGE.md、scripts/check_shotcard.py）

- [ ] 每镜 14 个字段齐全（景别/机位/运镜/构图/光线/色彩/动作起—中—止/环境动态/首尾帧/情绪）
- [ ] 景别、机位、运镜、构图用短码，不写整句英文
- [ ] 下一镜首帧 = 上一镜尾帧，逐字复用
- [ ] 连续同景别 ≤2 镜
- [ ] 一个镜头只做一件事（移动或变焦，不同时推+摇+变焦）
- [ ] 起幅和落幅都能独立成图
- [ ] 场景模板（v2.10 硬规则，见 scripts/check_scenario.py）：story.json 有 scenario 字段；有场景时 scenario_points 至少 2 条，内容型场景的镜头卡至少命中该场景 2 组关键词；不通过 = 镜头卡没写完，不进视频
