# 镜头卡审计（v1.9 新增，见 docs/SHOT_LANGUAGE.md、scripts/check_shotcard.py）

- [ ] 每镜 16 个字段齐全（景别/机位/运镜/构图/光线/色彩/动作起—中—止/环境动态/首尾帧/情绪/画面动什么/运镜理由 + camera_side/angle_change）
- [ ] 画面动什么（moving）填了：这镜什么在动至少一样；运镜理由（move_reason）三选一填了
- [ ] 机位多样性：全片平视正面 ≤2 镜；景别不连着三镜相同
- [ ] 黄金比例：人物头或眼睛落在画面横向约 38% 或 62% 处
- [ ] 配色表：每场一张色表；色块草图转黑白，人和背景分得开
- [ ] 首帧里有动作要用的东西；雨/帽子/纹身首尾帧都有；旁人反应首帧里提前摆好
- [ ] 景别、机位、运镜、构图用短码，不写整句英文
- [ ] 下一镜首帧 = 上一镜尾帧，逐字复用
- [ ] 连续同景别 ≤2 镜（v3.2：只看同一主角；反打轮流换人时，同景别连拍不算单调）
- [ ] 一个镜头只做一件事（移动或变焦，不同时推+摇+变焦）
- [ ] 起幅和落幅都能独立成图
- [ ] 场景模板（v2.10 硬规则，见 scripts/check_scenario.py）：story.json 有 scenario 字段；有场景时 scenario_points 至少 2 条，内容型场景的镜头卡至少命中该场景 2 组关键词；不通过 = 镜头卡没写完，不进视频
- [ ] 动态画布（v3.2，见 docs/DYNAMIC_CANVAS.md、scripts/check_shotcard.py）：格数 G = 实际镜数，不再是 N × 3；每段 1–3 格，一段纯对话无转场时该段 1 格，不硬凑 3 格；同段重复构图（景别 + 机位 + 环境 + 出场人物 + 动作起止完全相同）即不通过，合并为 1 格
