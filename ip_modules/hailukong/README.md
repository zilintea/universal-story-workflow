# 示例 IP 插件：海陆空小队（摘要版，完整圣经见原项目 BIBLE.md v1.0）

- 海：锦鲤小福，橙红锦鲤，年年有余，引路渡河
- 陆：白芝麻（奶油白，厨师帽 + 黄围巾，机灵）、绿豆（翠绿，头顶绿芽，力大）、蚂蚁阿勤（暖棕，勤劳，背芝麻包）、柿子柿柿（橙色柿子，事事如意）
- 空：喜鹊小喜（蓝白，深蓝翅长尾，送信侦察）、蜜蜂小忙（黄棕，棕眼短翅，采蜜勤劳）
- 世界：云水谷，夏日午后，无人类，无反派
- 场景：厨房小屋、柿子树果园、蚂蚁丘草地路、河湾荷花池、云岛瞭望台
