# 风格档案（v1.9）

每个风格一张卡：`id` + `alias`（用户说的简称，如吉卜力、皮克斯3D、定格动画）
+ `prompt`（描述性字段，进提示词）+ `desc_zh`。

**硬规则：品牌名只作选择简称，不直接写进提示词。**
提示词只写 `prompt` 栏的描述性词；`alias` 栏的品牌名只用来让用户点名，
不进图生图/图生视频/文生视频的提示词。
用户明确要求原样写品牌名时，才按用户的话写，并记在文字稿里。

常用风格先写在这里：ghibli、pixar3d、disneypixar3d、stopmotion、liveaction、inkwash、cel2d、guoman3d（v2.9 新增，3D国漫CG：金青色调、丁达尔光束、灵力粒子、水墨粒子，仙侠/神话主推）、whitefox（v3.4 新增，v3.6 改版，白狐风 · 新中式角色插画）。
用户新说一个风格，就新加一张卡，不改流程。
新风格卡只写 5 行：质感、人物、颜色、光线、运镜。

**白狐风是例外**：`whitefox.yaml` 不是 5 行小卡，而是一套完整提示词——风格块 + 人物构成块 + 群像块 + 场景槽 + 8 张比例卡 + 图/视频拼装模板，全收进这一个文件，比例卡在 `data/styles/whitefox/card_a–h.webp`。仅显式调用：只有用户说出 白狐风 / 白狐风格 / 现代水墨重彩 / 新中式角色插画 时才用，不进自动建议；工作流（v3.6）：出图不用抽卡，直接按提示词出图；出视频时以生成的图为参考图。比例仍从卡里挑一个写进提示词，比例卡保留作可选参考。构图按场景走，画面内文字可用汉字。
