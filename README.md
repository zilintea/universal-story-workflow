# Universal Story Workflow · 通用故事工作流

> **这是什么：** 通用剧集脚本工作流技能仓库。用户只给一句话提示，就能完整构建一个故事，先出文字，审核通过后再做视频。适用剧集、电影、短视频、系列预告、世界观概念片、角色登场片；中国典故、美国故事、原创 IP 都走同一流程。
> **安全只是说明文件：** `docs/SAFETY_OPTIONAL.md`、`docs/CHILD_SAFETY.md` 只是供查阅的说明，默认不加载，不参与审计，不当关卡。本技能是所有场景通用的版本。

## 操作重点（做之前先看这六条）

1. **先文字，后视频。** 文字稿是第一交付物，用户点头（关卡 1）才出画布，画布点头（关卡 2）才生成视频。
2. **画布先出、用户确认。** 三视图、故事板、场景画布锁死再进视频，画布错了后面全错。
3. **试点先行。** 每集先只做 1 段试点，用户点头（关卡 3）才批量做剩下 N−1 段；试点不过不烧后面。
4. **镜头卡 + 首尾帧锁定。** 每镜 14 字段短码，下一镜首帧 = 上一镜尾帧，上一段尾帧当下一段参考图。
5. **单独文件交付。** 视频按分镜单独生成、单独保存；音频单独；字幕单独带时间戳，不烧进视频；合并成片由用户选。
6. **只报成本、不先烧额度。** 换平台前先报单段成本和本集总段数 N，用户点头再烧；哪段错只重做哪段。

## 引用模式（只传编号，不传全文）

锁定表只写一次，之后每段只写编号，**绝不重复写描述**：

| 引用对象 | 第一次写 | 之后每段只写 |
|---|---|---|
| 角色 | 三视图 + 颜色卡 + DNA，编号 C1、C2…… | `C1` |
| 场景 | 场景画布，编号 S1、S2…… | `S1` |
| 物品 | 物品锁定表，编号 I1、I2…… | `I1` |
| 风格 | `data/styles/<id>.yaml`，编号如 `ghibli` | `风格 ghibli` |
| 镜头 | 镜头卡 14 字段短码 | `MCU / EL / STATIC` |
| 世界线 | 第 0 步世界空间线 | 地点编号 + 时间线 |

新内容才写全文；已锁定的内容只写编号。长提示词不是更专业，是更烧。

## 参数（用户指定，没说才用默认值）

| 参数 | 用户怎么说 | 默认值 |
|---|---|---|
| 成片时长 D | “直出 60 秒”“做 90 秒”“15 秒” | 30 秒（短视频 10–90 秒可选） |
| 视频段数 N | 由 D 算 | N = D ÷ 10（每段约 10 秒，是生成端单段长度） |
| 故事板格数 G | 由 D 算 | G = N × 3（30 秒 9 格，60 秒 18 格） |
| 画幅 | “竖屏”“方形” | 横屏 16:9 |
| 目标语言 | 用户一句话的语言 | 按用户那句话的语言 |
| 风格 | “吉卜力”“真人写实” | 用户不说不选 |

## 怎么安装（30 秒）

```bash
# 方式一：一键安装（推荐）
python3 scripts/install_skill.py --target muse        # 装到 Muse
python3 scripts/install_skill.py --target claude      # 装到 Claude
python3 scripts/install_skill.py --target workbuddy   # 交给 WorkBuddy 自主执行
python3 scripts/install_skill.py --target gpt --out ./gpt_instructions.md  # 生成 GPT 说明，粘贴进 GPT Instructions

# 方式二：手动复制
cp -r . ~/workspace/custom-skills/universal-story-workflow/   # Muse
cp -r . ~/.claude/skills/universal-story-workflow/            # Claude
```

装完不用配置，入口是 `SKILL.md`，元数据是 `skill.yaml`。

## 怎么使用（先文字，后视频）

1. **你只说一句话**，不用补设定，不用去外部工具操作。
2. **我先给你文字稿**：世界空间线、主题、角色、风格、镜头卡、旁白、审计表，全在文字稿里。
3. **你点头，我再做故事板、视频、音频。** 文字没通过，绝不生成视频、不烧积分。
4. 视频按分镜单独生成，每段约 10 秒；**先做 1 段试点，试点通过再批量**（共 N 段，N = D ÷ 10；默认 30 秒时 3 段，用户说直出 60 秒时 6 段）；合并成片由你选，不是默认。

## 怎么调用（一句话就行）

```
出一集[IP 名]，主题是[一句话]
讲一个[中国典故 / 美国故事]的故事
用通用工作流做[主题]，[风格，如吉卜力 / 真人写实 / 定格动画]
发生了[事件]，[受众，如给小朋友看 / 通用]
```

**调用示例：**

```
出一集海陆空小队，主题是送错的信
讲一个八仙过海的故事，真人写实风
讲一个卖炭翁的故事，吉卜力风格
发生了火灾，给小朋友看
做一道菜：红烧鱼
```

**默认值（文字稿里必须明示）：** 受众通用观众；目标语言按你那句话的语言；**时长文字 D 秒、视频 D 秒**（D 是用户指定的成片时长，没说默认 30 秒；短视频 10–90 秒可选；剧集/电影按 `docs/FORMATS.md` 选）；画面横屏 16:9。教学模式（小朋友 / 语言教学，见 `docs/TEACHING_MODE.md`）时才加词汇、句型、警示点；安全只是说明文件，不参与审计。

## 核心能力

1. **自我构思**：不只等用户给主题。用户只说“给我一个故事”或只给一个词，`conceive.py` + 结构库能出 3 个点子（主角、主题、物品、反转各不同），经审计初筛后挑一个，不用用户想点子。
2. **世界空间线（第 0 步）**：先画地图再写故事——地点线、时间线、世界规则，中国典故、美国故事都走同一张表。
3. **镜头语言卡**：每镜 14 个字段短码，首尾帧锁定（上一段尾帧当参考图），自然语言故事句不进提示词。
4. **旁白连续性**：旁白轨一整段连续自然语言，教学轨分开，句子不跳跃。
5. **风格档案**：`data/styles/`，品牌名只作选择简称，不进提示词。
6. **编排故事情节**：见 `docs/PLOT_ARRANGEMENT.md`。三幕节拍、因果链图、升级一次原则、伏笔- payoff 对照表，情节不是人物接力。
7. **单词高亮发音（教学模式）**：见 `docs/WORD_HIGHLIGHTING.md`。文字里词汇加粗 + 拼音/音标；音频里关键词慢读、重复、停顿；字幕里关键词变色（黄色），其余白色。

## 审计（七项，审计链里没有安全）

逻辑 + 语言 + 剪辑 + 人物一致性 + 场景一致性 + 流程（只做流程型剧集时查）+ 旁白连续性。安全只是说明文件，不参与审计。

## 确认关卡（四道，缺一不可）

文字 → 画布 → 试点 → 批量。每道都要用户点头才进下一步：文字稿点头才出故事板，故事板点头才生成视频，试点视频点头才批量，批量完成、合并由用户选。
