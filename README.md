# 通用故事工作流

一句话就能做出一集故事视频：你说一句话，我先写文字稿，你点头后再做视频。

- **能做：** 剧集、电影、短视频、系列预告、世界观概念片；中国典故、美国故事、原创 IP 都行。
- **入口：** `SKILL.md` 是主流程，执行时以它为准。`skill.yaml` 是技能元数据。
- **当前版本：** v3.8（2026-11-06）。

> 安全只是说明文件：`docs/SAFETY_OPTIONAL.md`、`docs/CHILD_SAFETY.md` 只是供查阅的说明，默认不加载，不参与检查，不当关卡。

---

## 30 秒上手

### 第 1 步：安装（一次就行）

```bash
python3 scripts/install_skill.py --target muse        # 装到 Muse
python3 scripts/install_skill.py --target claude      # 装到 Claude
python3 scripts/install_skill.py --target workbuddy   # 交给 WorkBuddy 自主执行
```

装完不用配置。想先看看装到哪，加 `--dry-run` 只打印路径，不复制。

### 第 2 步：发一句话

```
出一集海陆空小队，主题是送错的信
```

就这一句。想换风格、换时长、换语言，直接加在句子里：

```
讲一个八仙过海的故事，真人写实风，60 秒
```

### 第 3 步：点头四次，拿到视频

1. **看文字稿**——故事对不对？点头才继续。
2. **看画布**——人物、场景、机位对不对？点头才继续。
3. **看试点**——先只做 1 段视频给你看，对了才批量做剩下的。
4. **拿成片**——剩下的段 + 音频 + 字幕，单独文件给你；想合成一支再说。

**全程不会自动往下跑。** 每一关都要你点头，没点头就停在那，不烧额度。

## 一句话怎么说

照下面抄，改括号里的内容就行：

```
出一集[IP 名]，主题是[一句话]
讲一个[中国典故 / 美国故事]的故事
用通用工作流做[主题]，[风格，如吉卜力 / 真人写实 / 定格动画]
发生了[事件]，[给小朋友看 / 通用]
做一道菜：[菜名]
```

例子：

```
出一集海陆空小队，主题是送错的信
讲一个卖炭翁的故事，水墨风格
发生了火灾，给小朋友看
做一道菜：红烧鱼
```

## 默认值（你不说，就按这个来）

| 你不说 | 默认就是 |
|---|---|
| 时长 | 30 秒（短视频 10–90 秒可选；说"60 秒"就做 60 秒） |
| 画幅 | 横屏 16:9（说"竖屏"就改竖屏，全集不换） |
| 语言 | 默认中文（v3.0；你明确说"用英语讲"或"美国故事"时才改，见下面"语言规则"） |
| 人物形象 | 默认东方人物：东亚面孔、黑发、黑眼睛（v3.0；你明确指定其他背景时才改） |
| 风格 | 先给你建议：主推 1 个 + 备选 1 个；你没别的提示就用主推 |
| 受众 | 通用观众（说"给小朋友看"才切到教学/少儿模式） |
| 合并 | 不合并。视频、音频、字幕各交各的；你说"合并"才拼成一支 |

每段视频约 10 秒：30 秒 = 3 段，60 秒 = 6 段。故事板格数按实际镜数走，不再是每段固定 3 格——一段纯对话、没有转场时，该段只画 1 格，不硬凑（见"动态画布"）。

## 语言规则（v3.0，约束说明）

这五条是硬规则，写错即不通过：

1. **默认中文。** 人物类剧集你没特别指定时，目标语言一律中文，对话、旁白、字幕全是中文。
2. **默认东方人物。** 人物类剧集你没特别指定时，人物形象一律东方人物：东亚面孔、黑发、黑眼睛。
3. **指定了才改。** 只有你明确说了才改：比如"用英语讲"改语言，"美国故事"改语言和人物。只说一句话主题、不指定语言和人物时，按第 1、2 条默认走。
4. **语言要一致。** 对话、旁白、字幕必须和目标语言一致——中文片里不许混英文词，英文片里不许混中文。视频提示词用英文写画面描述，但里面的对话、旁白、字幕文本必须用目标语言写，不翻译。
5. **报告和内容分开。** 说明、审计结论用什么语言写可以配，但故事内容本身的语言只跟目标语言走，两者互不干扰。
6. **画面里禁止国家形象标志。** 国旗、国徽、旗帜等一律不出现：不进文化锚点，不进角色服装，不进场景布置，不进提示词。制服只写颜色和款式，不写徽章图案；招牌只写颜色和形状，不写旗帜。
7. **多语言对话（v3.2）。** 不同国家的人同框，各人说各人的语言：旁白始终用目标语言；对话按说话人走（故事里写清每人说什么语言，默认目标语言）；字幕用目标语言，非目标语言的对话行字幕写翻译；每句对话都按说话人的语言检查。
8. **画面内文字的语言（v3.3）。** 牌匾、招牌、旗帜、碑刻等画面内文字，用什么语言跟故事走，不跟提示词的语言走：中国场景一律汉字，不许出现英文字母；其他国家跟其语言。提示词里不写罗马拼音地名、人名（模型会直接抄上牌匾），地名只进旁白和字幕。
9. **白狐风画面内文字可用汉字（v3.6）。** 白狐风不再禁文字：春联、牌匾、灯笼字等按场景需要出现，只许汉字，字要写对；与第 8 条一致。出图不用抽卡，构图按场景走。
10. **七段式视频提示词（v3.7）。** 视频提示词按七段式拼：画风、镜头、构图与配色、人物、逐秒、声音、约束；逐秒 0–0.2 秒静止等于首帧、最后 0.3 秒停住等于尾帧。镜头卡 16 字段（加“画面动什么”“运镜理由”）。生成视频花钱之前先过提交前新视角审计，成片后过全片复核。
11. **音频合成归入工作流（v3.8）。** 删除“用户自行合成/调用语音 API”的操作说明：旁白与对话的音频由执行方按文本与时间戳合成后随片交付，用户不用自己合成、不用调语音 API；“换平台前报成本”改为“烧额度前报成本”。

非人物类内容（风光、美食、汽车、产品等）不受第 1、2 条管，按题材走。详细规则见 `docs/LANGUAGE_LOCK.md` 和 `docs/CHARACTER_DEFAULTS.md`。

## 四道关卡（为什么要你点头四次）

| 关卡 | 你看什么 | 不点头会怎样 |
|---|---|---|
| 1. 文字 | 文字稿：故事对不对、主题清不清 | 不出故事板、不生成视频 |
| 2. 画布 | 三视图 + 故事板 + 场景画布：人物、场景、机位对不对 | 不生成视频；哪格不对只改那格 |
| 3. 试点 | 1 段试点视频：镜头、首尾帧、风格对不对 | 不批量做剩下的段 |
| 4. 批量 | 剩下的段 + 音频 + 字幕：每段动没动、衔接顺不顺 | 不合并成片 |

道理很简单：文字错了，后面全错；试点错了，后面全烧额度。所以先文字、再画布、再试点、最后批量。

---

## 五条注意事项

1. **先文字，后视频。** 文字稿没通过，绝不生成视频——烧掉的额度追不回来。
2. **画面里不写字。** 生成的画面一律不带可读汉字，标题、字幕后期再加。
3. **上一段的尾帧，就是下一段的首帧。** 转场不会跳，人物场景不会漂。
4. **哪段错只重做哪段。** 不用整集重做。
5. **烧额度前先问成本。** 先报单段成本和总段数，你点头再烧。（教训：有人一个视频在豆包上测试，一个月用量一次用完。）

## 常见问题

**Q：视频里人物变样了（颜色、体型、标志物变了）怎么办？**
A：每段是独立生成的，没有跨段记忆。办法是第 1 步就锁死三视图（正面/侧面/背面 + 颜色卡），每段提示词逐字复用；成片对照三视图验收，漂了就重做那一段。

**Q：分镜之间转场跳跃怎么办？**
A：每镜用 14 字段镜头卡写，上一段尾帧当参考图，第一句写 `Continue from this exact frame.`。

**Q：一段生成失败怎么办？**
A：不重复原请求，改用更安全的讲法重拍那一段（比如不拍明火特写，只拍烟从锅里冒出来）。静态故事板图只能临时占位，不能当成片。

**Q：想换风格怎么办？**
A：文字稿阶段说一声就行。没说就用建议的主推风格；点名了就用点名的。

**Q：想做长一点，比如 90 秒或一集电视剧怎么办？**
A：直接说时长就行，段数按公式算（90 秒 = 9 段）。剧集/电影的规模见 `docs/FORMATS.md`。

**Q：做菜、做手工这种流程类的有什么特别？**
A：有六条硬规则（`docs/PROCESS.md`）：步骤顺序锁定、不跳步、材料不凭空出现、成品只在最后一步出现、热/锋利/火/电步骤必须有书面安全做法、你的创意只占一个槽位。

**Q：GPT 上能用吗？**
A：能。GPT 没有本地脚本环境，审计改用 `checklists/` 逐项文字自查，代替跑脚本。
