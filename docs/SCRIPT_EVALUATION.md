# 脚本自我评估（v1.4，按影视剪辑标准改写前）

## 评估对象
- conceive.py：出点子，初筛只看物品会毁、反转无伏笔
- check_story.py：查词汇、句型、对话长度、目标语言、警示点
- highlight_words.py：出高亮文本和 ASS 骨架
- make_canvas.py：出空白 9 格画布

## 按影视剪辑标准评估，旧脚本缺什么

| 剪辑标准 | 旧脚本有没有 | 后果 |
|---|---|---|
| 180 度轴线 | 没有 | 人物左右互换，观众分不清谁在跟谁说话 |
| 30 度规则 | 没有 | 同一角度同一景别连续切，成跳切 |
| 动作匹配 | 没有 | 动作断、重复、倒退 |
| 视线匹配 | 没有 | 人物看左，下一镜东西在右 |
| 物品连续 | 没有 | [物品 1]上一镜在[场景 A]，下一镜无故出现在[场景 B] |
| 场景连续 | 没有 | 场景颜色、固定元素无故变 |
| 景别节奏 | 没有 | 连续 3 镜同一景别，节奏单调 |
| 转场类型 | 没有 | 场景切换也用硬切，观众不知道换地方了 |

## 改写方案（本版已做）
- 新增 scripts/edit_check.py，专做剪辑 + 连续性检查，输入分镜 JSON，输出逐项通过/不通过
- 新增 docs/CONTINUITY.md、docs/EDITING_STANDARDS.md、checklists/continuity_audit.md
- SKILL.md 第 4 步审计改为三审计：逻辑 + 语言 + 剪辑/连续性，三表全过才写正式文字
- 字幕改为单独时间戳文件（见 docs/SUBTITLES.md），不再默认烧录
- 实测：好分镜通过，坏分镜（物品瞬移、轴线翻转、跳切、场景硬切）被 edit_check.py 拦下，见上一次测试输出
