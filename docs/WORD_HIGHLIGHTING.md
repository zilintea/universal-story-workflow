# 单词高亮规范（文字版 v1.7）

**发音规范不在本技能范围内，本技能不规定发音方式；语音合成包含在工作流内，音频由执行方按文字稿、对话/旁白文本、时间戳合成交付。**

## 文字里的高亮
每个关键词汇第一次出现时加粗，附母语意思，之后每次出现加粗，不重复解释（避免阅读断裂），词汇表里保留完整意思

## 字幕里的高亮
- 格式：ASS 字幕，关键词汇用黄色 `{\c&H00FFFF&}`，其余白色
- 关键词汇出现时，字幕只高亮该词，不整句变色
- 时间轴：高亮词的开始时间 = 音频中该词的开始时间，结束时间 = 该词结束 + 0.3 秒
- `scripts/highlight_words.py` 可把词汇表 + 剧本对话，跑出高亮文本和 ASS 骨架（时间轴需在配音完成后按实际音频对齐，不能凭空编时间）

## 检查
- 词汇表里每个词都有母语意思吗？
- 对话和旁白是目标语言吗？母语有没有进视频音频？
- 对话里每个词出现 ≥3 次吗？至少 1 次在笑点里吗？
- 字幕里高亮词与时间戳对齐吗？
