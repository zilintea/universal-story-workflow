# 历史过程题材（v3.15）

长时段工程 / 事件题材：筑墙、建城、修渠、造船——主体是人造结构或集体工程，时间跨度以年计。

## 根因

2026-11-15《秦长城：公元前二百二十年》实测：时间线写成“同一天黎明到黄昏”，把数年的工程压缩成了一天；6 段每段只拍一个静态活动，墙本身怎么长起来的过程一镜没有。这是 v3.14 刚修过的问题换了个题材重犯：一段一个状态，过程掉进缝里。v3.13 的时间跳跃线只写给生长题材，历史题材没有长时段过程概念；过程镜只绑了生长阶段交界，没绑建造工序交界；没有历史细节自查，工期、工序顺序没人查。

## 时间线：按史实写，不压缩

- 工期必须按史实写进文字稿（秦长城：秦始皇统一后动工，前 221 年起，蒙恬主持，约前 221–前 210 年，连接秦燕赵旧墙；具体年份不确定处写“未确认”，不编造）。
- 禁止把多年工程压缩成一天、一季，除非用户明确要求“一日”——用户没说，就按年写。
- 时间跳跃线按年 / 季 / 月写（例如：公元前 221 年春 → 前 219 年 → 前 217 年 → 前 214 年 → 前 212 年 → 前 210 年），段间间隔写清，同一镜内时间不换，白天不无故变夜晚。
- 阶段顺序 = 工序顺序 = 时间顺序（先备料后夯基，先墙体后烽火台），三者一致才通过。

## 主体与阶段

- 主体登记为 P1（例如 P1 长城），下挂建造阶段 P1-S1、P1-S2……，阶段编号终身不变；每阶段一张物品画布（阶段图版：正面 / 侧面 / 比例参照 + 材质 + 色值 + 状态 + 一句阶段 DNA + 非此物清单），与 v3.13 生长阶段同机制。
- 建造阶段示例（秦长城）：P1-S1 备料（料场、石堆）、P1-S2 夯基（地基、夯土层）、P1-S3 墙体（墙身长高）、P1-S4 砌石（石面、垛口）、P1-S5 烽火台、P1-S6 完工（长城伸进群山）。
- 阶段 DNA 只描述本阶段，不写其他阶段的形态；验收只对照本阶段图版，跨阶段形态不同不判漂移。

## 过程镜：每段默认是缩时过程镜

- 每个建造阶段交界处至少有一镜过程镜；每段默认是缩时镜（`transition: timelapse` + `process: {from_stage, to_stage}`），固定机位、同构图、时间跳。
- 拍的是结构变化本身：首帧旧态（地基）、尾帧新态（成墙），墙必须可见地长高、层数必须可见地变多；活动镜头（装车、夯土、扛石）只能作过程镜里的中段动作，不能替代过程本身。
- 参考图：旧阶段格裁剪 + 新阶段格裁剪两张（先后顺序 = 转变顺序），不传整张主画布；提示词写清起止两态。
- 验收：首帧对照旧阶段图版、尾帧对照新阶段图版；首尾结构没变是过程没拍到，不通过；尾帧演进到下一阶段的完成态是阶段溢出，不通过。

## 细节自查（扣细节）：出文字稿前必查

执行方在写文字稿之前自查，逐项写进文字稿“历史细节自查”一节，不通过不进画布：

- [ ] 工期：工程实际跨度与史实一致（年数、起止年份写清，不确定写“未确认”）
- [ ] 工序顺序：备料→夯基→砌墙→烽火台→完工，顺序符合建造逻辑，阶段顺序 = 工序顺序 = 时间顺序
- [ ] 工具与材料：夯具、石块、料车、绳索符合时代，无现代工具、机械
- [ ] 服饰与人数：民夫、士卒服饰符合时代，人数规模不写具体数字时不编造
- [ ] 结构：墙体做法（夯土为主、砖面为后世）写清，未做考古复原级区分时在文字稿里明示

## story.json

- `historical_process`: `[{id, name, stages: [{id, name, item_sheet}]}]`，`time_jump_line`: 段间间隔列表（例如 `["公元前221年春", "前219年", "前217年", "前214年", "前212年", "前210年"]`），`master_canvas` 必填。
- `shots` 字段可选；有该字段时过程镜的 `from_stage`/`to_stage` 须是同一主体的相邻建造阶段，脚本 `check_story.py` 查。
