# 角色辨识度（v3.21 新增，硬规则，通用）

## 解决的问题

女主的提示词大家都会写：大眼睛、小脸、长发、白皮肤、纤细。写完一出图，十个女主长得像一家人。白、幼、瘦，换件衣服就是下一部的女主。

问题不在模型，在提示词。你只写了“漂亮”，模型就给你一张平均脸。

## 结论：辨识度靠三样东西

1. **体态。** 高挑的、娇小的、丰腴的、结实的、纤薄的，站在那里的轮廓先于脸被记住。
2. **脸上的“记号”。** 泪痣、雀斑、单眼皮、挑眉、微卷的碎发、旧伤。只写“好看”，得到的永远是同一张脸。
3. **衣服的面料和做旧程度。** 白大褂、机车皮衣、真丝、粗针织、铠甲，面料一换，人的职业和性格就跟着换；磨损、做旧让角色可信。

## 顺序：先定体态，再定记号，最后选面料

**按这个顺序改。顺序别反过来。先想“她穿什么裙子”的人，最后做出来的都是同一个衣架子。**

| 顺序 | 定什么 | 写什么 | 错了会怎样 |
|---|---|---|---|
| 1 | 体态 | 身高、肩宽、胖瘦、站姿、重心 | 体态不定，十个人一个轮廓 |
| 2 | 脸上的记号 | 泪痣、雀斑、单眼皮、挑眉、碎发、旧伤，至少一处 | 只写“好看”，得到同一张平均脸 |
| 3 | 面料与配色 | 面料（真丝/粗针织/皮衣/铠甲）、做旧程度、配色 | 面料不写，职业和性格出不来 |

体态先于脸，记号先于妆，面料先于颜色。三样缺一样，辨识度就掉一档。

## 角色设定图版式（五格，一张图）

三视图升级为一张角色设定图，同一套版式，只换人物、发型、服装三块：

| 位置 | 内容 | 作用 |
|---|---|---|
| 左侧 | 正面、背面两个全身站姿 | 头部高度对齐，锁体态与服装 |
| 中间 | 正面面部大特写 | 锁脸、锁记号 |
| 右上 | 左侧脸、右侧脸特写 | 转头、侧身有对照，脸不跑 |
| 右下 | 四个细节特写 | 发饰、腰带、鞋、配饰，各一格 |

这张图做出来不是为了好看，是为了后面每一个镜头都拿它当参考。人物转头、侧身、走远，模型都有地方可以对照，脸和衣服才不会跑。

## 角色 DNA 的写法（按三样拼）

角色 DNA 一句话，逐字复用，顺序固定：**体态 + 脸上的记号 + 面料/服装**。

- 体态在前：身高、肩宽、胖瘦、站姿，一句话写清轮廓。
- 记号在中：至少一处脸上的记号，写进 DNA，不只写在设定图里。
- 面料在后：面料 + 做旧程度 + 主色，服装一句话。

DNA 里三样缺一样，`scripts/character_check.py` 视为 DNA 不完整，不通过，不进视频。

## 检查（任一项不过，角色不通过，不进视频）

- [ ] 体态、记号、面料三样齐全，顺序是体态 → 记号 → 面料
- [ ] 记号至少一处，且在正面特写、左侧脸、右侧脸三处一致
- [ ] 五格齐全（正面/背面全身、面部特写、左右侧脸、四个细节）
- [ ] 所有视图是同一人物，脸型、发型、服装、配饰完全一致
- [ ] 面料写清种类与做旧程度，不只写颜色
- [ ] 无文字、无水印、无已知 IP 造型

## 与人物一致性的关系

本文件是 `docs/CHARACTER_CONSISTENCY.md` 的升级：三视图从“正面/侧面/背面三张”升级为“五格角色设定图”，角色 DNA 从“一句话”升级为“体态 + 记号 + 面料三段式”，其余规则不变——DNA 逐字复用、逐段验收、连续两次漂移改拍法，仍按人物一致性规范执行。
