# 字幕规范（v1.4 改版：单独的带时间戳文件，不内嵌）

**改版说明：v1.3 的“内嵌字幕（burn-in）”作废。本版起，字幕一律是单独的、带时间戳的文件，不烧进视频画面。视频原片保持干净，用户需要字幕时，播放器加载字幕文件即可。**

## 文件格式（二选一，默认 SRT，教学用 ASS）

### SRT（默认，播放器通用）
```
1
00:00:00,000 --> 00:00:04,500
[Character C1] cooks in [Scene S1].

2
00:00:05,000 --> 00:00:09,500
Smoke comes from the pot.
```
- 每条：序号、开始 --> 结束（毫秒，逗号分隔）、英文文本、空行
- 时间戳必须与音频/画面对齐：对话出现时出，不提前、不滞后整句
- 每段视频对应一个字幕文件，或整集一个字幕文件，时间戳连续，不重叠、不留空段超过 1 秒

### ASS（教学用，关键词变色，但仍是单独文件，不烧录）
- 格式与 v1.3 相同：关键词汇黄色 `{\c&H00FFFF&}`，其余白色，字号 24，底部居中
- 文件名：subtitles_en.srt / subtitles_en.ass，放在 subtitles/ 目录，与视频文件同名对应（clip1.mp4 → clip1.srt）
- ASS 文件本身不进视频，播放器加载时才显示颜色

## 时间戳规则
- 旁白句：开始时间 = 旁白音频中该句开始时间，结束 = 该句结束 + 0.3 秒
- 对话句：开始时间 = 对话音频中该句开始时间，结束 = 该句结束 + 0.3 秒
- 跟读留白：跟读句结束后留 2 秒空档，字幕上不写“请跟读”，只留时间空档
- 验收：字幕文件用文本检查时间戳是否递增、是否重叠、是否超出视频时长；不抽视频帧验收字幕（因为字幕不在画面里）

## 禁止
- 不再默认烧录字幕进视频；用户明确要求烧录时，才另出一套烧录版，且原片和烧录版分开保存、分别命名
- 字幕文件里不写中文（中文只在词汇表和教师备注里），字幕文本只用英文
