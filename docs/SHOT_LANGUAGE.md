## 一句话镜头公式（写分镜就套这个）

```
[景别] + [机位/角度] + [运镜(速度+方向)] + [节奏] + 主语 + 动作(起—中—止，快镜 2–3 连发) + 环境动态 + [光线] + [情绪落点]
```

## 镜头卡字段（每镜必填，缺一项不进视频）

| 字段 | 短码/取值 | 说明 |
|---|---|---|
| 景别 scale | EWS / WS / MS-FULL / MS / MCU / CU / ECU / INS | 见手册 3.1；连续同景别 ≤2 镜 |
| 机位 angle | 下表十种，见“机位角度全表” | 同一场景 camera_side 不变 |
| 运镜 move | 下表十七种，见“运镜全表” | 一个镜头只做一件事；起幅落幅都能独立成图 |
| 节奏 tempo | 快 / 中 / 慢 | 默认 中；打斗/追逐/冲击场面默认 快；凝视/对峙/收尾呼吸用 慢。新稿必填，旧稿无此字段按 中 计，不追溯 |
| 构图 comp | 下表九种，见“构图全表” | 画面只留一个最亮的信息点 |
| 光线 light | 方向 + 质感 + 色温，如 `top-left hard 5600K` | 见手册 3.5；三件套，不写形容词 |
| 色彩 color | 主色 70% / 辅色 20% / 点缀 10%，写 HEX 或色名 | 全片只 5–7 个色块，见手册 3.6 |
| 动作 action | 起—中—止三段式 | 如：手抬起 → 手停在半空 → 手落下；动作不能断、不能重复、不能倒退；快镜可在起—中—止里写 2–3 个连发小动作（beats 字段写个数） |
| 动作数 beats | 1–3 | 默认 1；快节奏镜可 2–3 个连发动作节拍（出剑 → 格挡 → 反击），beats 写个数；慢镜只 1 个 |
| 画面动什么 moving | 摄影机 / 焦点 / 光线 / 飘过物 / 小动作，至少一样 | 每镜必填；写不出来说明这镜还没想好，重想；该静的地方静 |
| 运镜理由 move_reason | 写场景需求：这个动作非这个运镜不可的理由（例：罗盘金光乍起用急推、符火三角阵形用俯拍静止、鬼身消融用抽帧） | 理由与动作对不上即不通过；不能只写“跟人或物走 / 推近给特写 / 拉远”三选一 |
| 环境动态 env | 烟/水/风/人群/光变化 | 不写环境动态，画面像 PPT |
| 首帧 first | 连续镜：上一镜尾帧的文字描述，逐字复用；切换镜：本镜自己的开场画面（新主体已在动中） | 连续镜首帧 = 上一镜尾帧；切换镜首帧 ≠ 上一镜尾帧 |
| 尾帧 last | 本镜结束时的文字描述 | 连续镜的尾帧 = 下一镜首帧，逐字复用；切换镜的尾帧只作衔接参考 |
| 情绪 emotion | 0–10 分 + 一个词 | 如 7/10 不安；爆发后必须有一次退回远景的呼吸 |
| 特殊手法 trick | 下表五种，见“特殊手法全表”，15s ≤2 种，60s ≤4 种 | 手法是盐，不是饭 |

## 机位角度全表（v3.19 并入，原 docs/CAMERA_MOVES.md）

| 短码 | 中文 | 用法 / 情绪 | 注意 |
|---|---|---|---|
| EL | 平视 | 默认视角，平等、对峙 | 全片平视正面最多两次 |
| LOW | 低机位 | 仰拍，人物显高大、压迫 | 别连着三镜都用 |
| WORM | 极低机位仰拍 | 镜头几乎贴地仰拍，强势、紧张、即将行动 | 地面要入画，否则和 LOW 没区别 |
| HIGH | 高机位 | 俯视，人物显弱小、被压制 | 与 TOP 的区别：HIGH 带透视，TOP 是正上方 |
| TOP | 上帝视角 | 正上方鸟瞰站位、空间关系、“被监视”的压迫感 | 地面裂纹与阴影要清晰 |
| AERIAL | 航拍 | 大范围空间、收尾宏观场面 | 与 TOP 的区别：AERIAL 带飞行感、可移动 |
| DUTCH | 荷兰角 | 画面倾斜，不安、失衡、失控 | 慎用，一集最多一次 |
| OTS | 过肩 | 前景一人肩背、后景另一人，包抄与前后层次 | 前景肩不能挡住后景人脸 |
| POV | 主观视角 | 镜头就是角色的眼睛 | 只在用户点名时用 |
| WAIST | 过腰镜头 | 机位在腰部高度，前景带装备与人物关联 | 视线从道具移到人物，装备与角色建联系 |

## 运镜全表（v3.19 并入）

| 短码 | 中文 | 用法 / 情绪 | 注意 |
|---|---|---|---|
| STATIC | 静止 | 凝视、对峙、等一个动作发生 | 该静的地方静，别为了动而动 |
| PUSH | 推近 | 推向人物/细节，情绪收紧 | 尾帧可直接把首帧裁一块再放大 |
| PULL | 拉远 | 拉开距离，揭示环境、收尾 | 爆炸收尾、战场全景常用 |
| PAN | 摇摄 | 横向扫过场景、跟人转头 | 速度要匀，别甩过头 |
| TRACK | 跟拍 | 摄影机与主体同速移动，陪跑 | 主体别出画 |
| FOLLOW | 跟随 | 跟在人物身后走 | 与 TRACK 的区别：FOLLOW 在身后，TRACK 在侧面 |
| CRANE | 升降 | 从低到高揭示包围圈、从高到低落进现场 | 起幅落幅都能独立成图 |
| ORBIT | 环绕运镜 | 相机围绕人物做圆周运动，背景不断变化，动态包围感 | 人物相对静止、背景不断变化 |
| WHIP | 甩镜 | 快速甩过，切换目标、制造冲击 | 甩的过程要糊，落点要实 |
| ZOOM | 变焦 | 镜头内推拉，不动摄影机 | 别和 PUSH/PULL 混用同一镜 |
| RACK | 焦点转移 | 焦点从前景移到后景（或反向），引导观众发现线索 | 前景遮挡的搭档：前景模糊物体遮挡、后景人物清晰 |
| CRASHZOOM | 急推 | 瞬间变焦到特写，惊吓、发现、强调 | 一集最多两次，多了就廉价 |
| DOLLY | 滑轨 | 轨道上平滑推拉，比手持稳、比变焦实 | 起幅落幅构图要一致 |
| HANDHELD | 手持 | 晃动跟拍，临场感、紧张、纪实 | 幅度要小，别晕 |
| SLOWMO | 慢动作 | 冲击瞬间拉长：扑击、换弹、爆炸 | 写进 move 字段（速度技巧，借 move 位） |
| ONETAKE | 一镜到底 | 全程不切，跟拍到底 | 提前走位排练，失败成本高 |
| STEP | 抽帧 | 逐帧跳跃、卡顿感，诗意或恍惚 | 别和慢动作同镜混用 |

## 特殊手法全表（v3.19 并入）

| 手法 | 用法 | 注意 |
|---|---|---|
| 慢动作 | 冲击瞬间拉长（扑击、换弹、爆炸） | 见 move SLOWMO，同一镜只写一处 |
| 抽帧 | 诗意卡顿、恍惚、回忆 | 见 move STEP |
| 快速剪辑 | 枪口火光、弹壳、倒地，三连切 | 剪辑节奏，不是运镜；别在同一段里又慢动作又快剪 |
| 定格 | 动作停在最高点一帧 | 收尾或转场用 |
| 升格 / 降格 | 高速拍、慢速放（升格）或反之 | 和慢动作别重复算两种 |

## 按场景需求选镜（v3.19 新增）

选镜先看场景需求，再从上表挑，不许只用特写 / 推近 / 跟拍 / 静止四件套凑数。
下表是首选，不是唯一解；动作本身没给理由的运镜，一律不选。

| 场景需求 | 首选 | 为什么 |
|---|---|---|
| 对峙亮相、压迫开场 | WORM / LOW + PUSH | 贴地仰拍，地面入画，人物显强势 |
| 鬼魅、不安、失衡 | DUTCH + STATIC | 画面倾斜，静止凝视更瘆 |
| 惊吓、发现、法器发威 | CRASHZOOM | 瞬间到特写，冲击 |
| 冲击瞬间（剑光、火星、扑击） | WHIP / CRASHZOOM / TRACK + 切至 | 快动作 + 硬切，先快后看清；慢动作不作首选 |
| 慢动作点缀（一处高光） | SLOWMO | 全片最多 1 次，只作点缀；不许连续两镜都用，不许每个冲击点都用 |
| 追逐、缠斗、连发动作 | TRACK / WHIP + 快 tempo + beats 2–3 | 一镜多打，动作连发，镜长 2–3 秒 |
| 阵法几何（符火三角、站位） | TOP + STATIC | 正上方看清几何关系 |
| 线索转移（鬼丝→手腕） | RACK | 焦点引导观众发现 |
| 逼近压迫（剑尖抵眉心） | DOLLY | 轨道平滑推近，比变焦实 |
| 消融、恍惚、闪烁 | STEP | 抽帧卡顿，鬼身不稳 |
| 收尾、消散 | TOP + PULL | 上帝视角拉远，宏观收束 |
| 临场喘息、收束 | HANDHELD | 微晃，呼吸感 |
| 包围、缠斗 | ORBIT | 背景不断变化，动态包围感 |
| 切换目标、制造冲击 | WHIP | 甩的过程糊，落点实 |

**多样性硬规则（v3.19）：**
- 60 秒片同一运镜最多 2 次；特写 + 推近组合全片最多 2 镜；平视正面最多两次。
- 景别全身 / 半身 / 特写轮换，不连着三镜同一景别；机位不连着三镜同一个。
- 写完剧本先列全片运镜清单：每种运镜出现次数、每种机位出现次数，超限先改再进画布。
- 慢动作上限（v3.20）：SLOWMO 全片最多 1 次（60 秒片）；连续两镜不许都是慢动作；
  快 tempo 的镜不许用 SLOWMO（快慢矛盾，脚本不通过）。
- 打斗 / 动作场面（v3.20）：每镜 2–3 秒，每段可 3–4 镜（段仍约 10 秒）；
  快节奏镜占比 ≥ 一半；快镜的首 / 中 / 尾三帧必须各不相同，三帧几乎一样 =
  静态 = 节奏不通过。
- 选镜口诀（动作片典型组合）：近景压迫（WORM / LOW）→ 道具关联（WAIST）→
  俯拍空间（TOP）→ 环绕动态（ORBIT，核心）→ 焦点 / 景深变化（FG + RACK）→
  爆炸收尾（PULL + TOP）。

## 节奏（v3.20 新增：打斗不能慢）

根因：七段式模板头尾冻帧 + 镜头卡无速度字段 + 选镜表把冲击瞬间默认给慢动作，
三层叠加，动作片必然平淡。用户的快词（暴涨、直扑、横削、轰然、甩动、抢步、陡然）
翻成提示词时不许翻成慢词。

- tempo 快：动作快、镜内动作多、剪辑点密；打斗 / 追逐 / 冲击场面默认 快。
  tempo 慢：凝视、对峙、收尾呼吸。默认 中。
- beats：快镜一镜 2–3 个连发动作节拍，箭头连写（出剑 → 格挡 → 反击）；
  中 / 慢镜一镜 1 个。
- 镜长：打斗场面每镜 2–3 秒，每段 3–4 镜；文戏仍每镜 5 秒、每段 2 镜。
- 速度词：动作正文与逐秒里写速度词（骤然、猛地、瞬间、闪电般、残影、呼啸、
  劈、砸、甩、撞）；禁止把用户的快词翻成“平静地、缓缓地、慢慢地”。
- 慢动作是点缀：全片最多 1 次，留给最值得拉长的一处高光；其余冲击点一律
  快动作 + 硬切。

## 视频提示词拼装顺序（七段式，v3.7，见 templates/video_prompt_7seg.md）

每段视频按这个顺序拼：【画风】【镜头】【构图与配色】【人物】【逐秒】【声音】【约束】。
【逐秒】是核心：0–0.2 秒静止等于首帧，最后 0.3 秒停住等于尾帧；中间每秒写谁做什么。
例外（v3.20 动作版）：快节奏段不冻头尾——开场即在动中，尾帧是动作进行中的一帧；
见 templates/video_prompt_7seg.md 动作版。
旧 6 段拼装（运镜/主体动作/环境动态/摄影参数/光线变化/情绪落点）作废，摄影参数
（焦段 + 光圈 + 帧率 + 快门 + 稳定方式）写进【镜头】段。

提示词里不写故事、不写形容词堆砌、不写品牌名。风格、角色、场景三段共用文本只写一次，
之后每镜只写 ID（见 `docs/TOKEN_BUDGET.md`）。画面内文字按 v3.3/v3.6 规则另行处理。

## 分镜硬规则（v3.7 新增，见 docs/EIAN_HANDBOOK_REVIEW.md）

- 机位多样性：全片平视正面最多两次，其余用俯拍、仰拍、从背后、过肩、透过东西拍；
  景别全身/半身/特写轮换，不连着三镜同一景别。
- 运镜多样性（v3.19）：按“按场景需求选镜”一节调用；60 秒片同一运镜最多 2 次，
  特写 + 推近组合全片最多 2 镜；写完剧本先列全片运镜清单，超限先改再进画布。
- 黄金比例：人物头或眼睛落在画面横向约 38% 或 62% 处，不放正中间。
- 配色表 + 黑白检查：画第一张图之前定配色，每场一张色表（哪场用什么颜色）；
  色块草图转黑白，人和背景分不开即明暗对比不够，重调配色。
- 参考片逐帧量：镜头语言写不清时，找参考片逐帧看，量出机位、进出画比例再模仿；
  没参考片才按上面规则自己构思。
- 结构默认片段式：每镜不用接戏，最稳；连贯式只在用户点名时用，接戏逐对核对。

## 首尾帧锁定 SOP（v1.9 新增，试点已验）

1. 每段生成完，抽最后一帧存为 `clipN_last_frame.jpg`。
2. 下一段生成时，把该帧当参考图传进去，提示词第一句写
   `Continue from this exact frame.` + 本段镜头卡。
3. 验收：抽本段 0.5s / 5s / 9.9s 三帧，核对人物、场景、机位、光线；
   任一项与首帧不符即不通过，只重做该段，不整批重做。
4. 试点证据（2026-11-05，某集第 2 段）：旧纯文字版背景跑到集市、人换了一个；
   镜头卡 + 尾帧参考版同一个人、同一个场景、同一片背景，姿势全程不动。
   结论：勉强可以，未满分；先按此标准写进技能，跑完一集再评。
5. 先画内容最多的那张（一般是尾帧），再由它改出首帧，保证两张图机位、构图一致。
   同地点同机位的镜，直接在前一张图上改，不重新画。
6. 动作要用的东西，首帧里必须有；雨、帽子、纹身这类容易拍丢的东西，首帧和尾帧都要画上。
   旁人反应首帧里提前摆好：一个人在前面做事，另一个人在后面，脸朝镜头。
7. 推近的镜头：尾帧可以直接把首帧裁一块再放大；首尾帧构图完全一样等于镜头不动，
   没有慢慢推进的效果。
8. 提交给视频生成之前检查：首帧和尾帧尺寸一致、宽高比正确；有问题提前裁好。
9. **连续 / 切换（v3.10，影视逻辑硬规则）：** 镜头卡可选字段 `transition`，`continuous`（默认，缺字段即连续）或 `cut`。同一主体、同一机位、动作不断流，下一镜是连续镜，首帧 = 上一镜尾帧，逐字复用；切到新主体、新角度、新地点，下一镜是切换镜，首帧写本镜自己的开场画面——新主体已在动中（例：狗听到喊声竖起耳朵、猫转身跑向小路、湿毛微距特写），不许复刻上一镜尾帧，否则下一段开场是静止的。切换必须真实改变主体 / 地点 / 景别三者至少其一，否则是贴错标签的连续镜。衔接靠动作和声音跨切（例：小宝的喊声未断，画面切到大黄竖耳），不靠首帧复刻。
10. **缩时镜 timelapse（v3.13，第三种镜头类型，见 `docs/GROWTH_SEQUENCE.md`）：** `transition` 第三个取值 `timelapse`。同机位、同构图，时间跳；首帧 = 同构图新阶段，不等于上一镜尾帧；免首尾帧相等规则、免 30 度规则、免切换三换一规则（换的是时间）。转场配日期 / 间隔字幕，后期叠加。机位、构图与上一镜相同且时间间隔已写清即通过；机位相同但没写时间间隔，是贴错标签的连续镜，不通过。
11. **过程镜 process shot（v3.14，缩时镜的一种，见 `docs/GROWTH_SEQUENCE.md`）：** 拍转变过程本身的镜头，`transition` 取 `timelapse`，另加 `process: {from_stage, to_stage}`。动作起—中—止就是转变：首帧旧阶段末态、尾帧新阶段初态（刚到达，不展开）；每个相邻阶段交界处至少有一镜过程镜。首帧已是新阶段（过程没拍到）或尾帧演进到新阶段展开态（阶段溢出），两种都不通过。
10. **切换开场的视频参考图（v3.10）：** 本段首镜是切换镜时，参考图改传三视图（只锁人物，不当开场帧），提示词不写 `Continue from this exact frame.`，直接写本段首镜自己的首帧画面；连续开场才用上一段尾帧当参考图、第一句写 `Continue from this exact frame.`。

## 故事板生成规则

- 故事板先出文字版（9 格文字卡），文字通过了再出图；图不通过只改那一格。
- 9 格合在一张图里时，每格只分到一两句提示词，必然每格重猜一次；
  因此故事板图只作构图参考，不作视频生成的参考图；视频参考图只用上一段尾帧。
