## 一句话镜头公式（写分镜就套这个）

```
[景别] + [机位/角度] + [运镜(速度+方向)] + 主语 + 动作(起—中—止) + 环境动态 + [光线] + [情绪落点]
```

## 镜头卡字段（每镜必填，缺一项不进视频）

| 字段 | 短码/取值 | 说明 |
|---|---|---|
| 景别 scale | EWS / WS / MS-FULL / MS / MCU / CU / ECU / INS | 见手册 3.1；连续同景别 ≤2 镜 |
| 机位 angle | EL / LOW / HIGH / DUTCH / TOP / AERIAL / OTS / POV | 见手册 3.2；同一场景 camera_side 不变 |
| 运镜 move | STATIC / PUSH / PULL / PAN / TRACK / FOLLOW / CRANE / ORBIT / WHIP | 一个镜头只做一件事；起幅落幅都能独立成图 |
| 构图 comp | THIRDS / SYMM / FRAME / FG / LEAD / NEG / DIAG / LAYERS | 见手册 3.4；画面只留一个最亮的信息点 |
| 光线 light | 方向 + 质感 + 色温，如 `top-left hard 5600K` | 见手册 3.5；三件套，不写形容词 |
| 色彩 color | 主色 70% / 辅色 20% / 点缀 10%，写 HEX 或色名 | 全片只 5–7 个色块，见手册 3.6 |
| 动作 action | 起—中—止三段式 | 如：手抬起 → 手停在半空 → 手落下；动作不能断、不能重复、不能倒退 |
| 画面动什么 moving | 摄影机 / 焦点 / 光线 / 飘过物 / 小动作，至少一样 | 每镜必填；写不出来说明这镜还没想好，重想；该静的地方静 |
| 运镜理由 move_reason | 跟人或物走 / 推近给特写 / 拉远，三选一 | 运镜必须有理由，不能为了动而动 |
| 环境动态 env | 烟/水/风/人群/光变化 | 不写环境动态，画面像 PPT |
| 首帧 first | 上一段尾帧的文字描述 + 参考图路径 | 首帧 = 上一段尾帧，逐字复用 |
| 尾帧 last | 本段结束时的文字描述 | 尾帧 = 下一段首帧，逐字复用 |
| 情绪 emotion | 0–10 分 + 一个词 | 如 7/10 不安；爆发后必须有一次退回远景的呼吸 |
| 特殊手法 trick | 见手册第 5 章 16 式，15s ≤2 种，60s ≤4 种 | 手法是盐，不是饭 |

## 视频提示词拼装顺序（七段式，v3.7，见 templates/video_prompt_7seg.md）

每段视频按这个顺序拼：【画风】【镜头】【构图与配色】【人物】【逐秒】【声音】【约束】。
【逐秒】是核心：0–0.2 秒静止等于首帧，最后 0.3 秒停住等于尾帧；中间每秒写谁做什么。
旧 6 段拼装（运镜/主体动作/环境动态/摄影参数/光线变化/情绪落点）作废，摄影参数
（焦段 + 光圈 + 帧率 + 快门 + 稳定方式）写进【镜头】段。

提示词里不写故事、不写形容词堆砌、不写品牌名。风格、角色、场景三段共用文本只写一次，
之后每镜只写 ID（见 `docs/TOKEN_BUDGET.md`）。画面内文字按 v3.3/v3.6 规则另行处理。

## 分镜硬规则（v3.7 新增，见 docs/EIAN_HANDBOOK_REVIEW.md）

- 机位多样性：全片平视正面最多两次，其余用俯拍、仰拍、从背后、过肩、透过东西拍；
  景别全身/半身/特写轮换，不连着三镜同一景别。
- 黄金比例：人物头或眼睛落在画面横向约 38% 或 62% 处，不放正中间。
- 配色表 + 黑白检查：画第一张图之前定配色，每场一张色表（哪场用什么颜色）；
  色块草图转黑白，人和背景分不开即明暗对比不够，重调配色。
- 参考片逐帧量：镜头语言写不清时，找参考片逐帧看，量出机位、进出画比例再模仿；
  没参考片才按上面规则自己构思。
- 结构默认片段式：每镜不用接戏，最稳；连贯式只在用户点名时用，接戏逐对核对。

## 首尾帧锁定 SOP（v1.9 新增，试点已验）

1. 每段生成完，抽最后一帧存为 `clipN_last_frame.jpg`。
2. 下一段生成时，把该帧当参考图传进去，提示词第一句写
   `Continue from this exact frame.` + 本段镜头卡。
3. 验收：抽本段 0.5s / 5s / 9.9s 三帧，核对人物、场景、机位、光线；
   任一项与首帧不符即不通过，只重做该段，不整批重做。
4. 试点证据（2026-11-05，某集第 2 段）：旧纯文字版背景跑到集市、人换了一个；
   镜头卡 + 尾帧参考版同一个人、同一个场景、同一片背景，姿势全程不动。
   结论：勉强可以，未满分；先按此标准写进技能，跑完一集再评。
5. 先画内容最多的那张（一般是尾帧），再由它改出首帧，保证两张图机位、构图一致。
   同地点同机位的镜，直接在前一张图上改，不重新画。
6. 动作要用的东西，首帧里必须有；雨、帽子、纹身这类容易拍丢的东西，首帧和尾帧都要画上。
   旁人反应首帧里提前摆好：一个人在前面做事，另一个人在后面，脸朝镜头。
7. 推近的镜头：尾帧可以直接把首帧裁一块再放大；首尾帧构图完全一样等于镜头不动，
   没有慢慢推进的效果。
8. 提交给视频生成之前检查：首帧和尾帧尺寸一致、宽高比正确；有问题提前裁好。

## 故事板生成规则

- 故事板先出文字版（9 格文字卡），文字通过了再出图；图不通过只改那一格。
- 9 格合在一张图里时，每格只分到一两句提示词，必然每格重猜一次；
  因此故事板图只作构图参考，不作视频生成的参考图；视频参考图只用上一段尾帧。
