# 生长序列：变形主体的时间链（v3.13）

## 问题

v3.11/v3.12 的画布系统有三条隐含假设，生长题材（种子发芽、莲藕开花结果、
毛毛虫变蝴蝶、盖房子、季节更替）全撞上：

1. **物品 = 定形。** 物品画布锁死形状、尺寸、材质、状态，任一项不符即不通过。
   但生长主体每阶段换一个形态：藕 → 芽 → 叶 → 花 → 蓬 → 子，形状材质全变。
   锁一张图版，后面每段都判不通过；拆成六件物品，又丢了“同一株”的身份。
2. **主画布 = 全量参考。** 每段第一张参考图永远是整张主画布，主画布上所有
   形态同时出现。段 2 拍芽时参考图里已经有一朵花，模型会把未来的形态泄漏进
   早期的镜头——防漂移的机制自己变成漂移源。
3. **时间中途不换 + 首帧等于上一镜尾帧。** 世界线要求时间不换，连续镜要求
   首帧复刻上一镜尾帧。但缩时摄影恰恰是机位不动、时间跳几周：下一镜首帧
   不可能是上一镜尾帧。技能把“同一机位”和“连续时间”混成了一回事。

## 生长主体 P1：一个主体，多阶段图版

- 主体编号 P1、P2……（与 C1、I1、S1 同级引用，提示词只写编号）。
- 每阶段一张物品画布，编号 P1-S1、P1-S2……，阶段编号终身不变，
  重做只升版本号，不改编号、不删旧版。
- 每阶段图版与普通物品画布同要求（见 `docs/ITEM_CANVAS.md`）：
  正面 / 侧面 / 比例锚点 + 材质 + 色值 + 状态 + 一句阶段 DNA + 非此物清单。
  阶段 DNA 只描述本阶段形态（例如“莲蓬：绿色圆盘，表面多孔，约手掌大小”），
  不写其他阶段。
- 阶段划分按形态走：形态变了才新开一阶段；一段可含多个阶段时，
  镜头卡按镜分阶段，不按段分。
- 比例锚点：非手持主体不用“手中比例”，用固定参照物
  （池塘边、叶片、与人同框比大小），写清可比尺寸。
- 状态词表：完好 / 破损之外加生长态——发芽、抽叶、开花、结果、枯萎、落叶。
  生长态是正常状态，不判破损；状态变化须有时间间隔支撑，不须镜内动作。

## 验收：对照本阶段图版，不对照全集

- 每段成片帧只对照本阶段的图版核对形状、尺寸、材质、数量、状态；
  跨阶段形态不同不判漂移，判据是三项：同一主体编号、阶段顺序正确、
  段间有写清的时间间隔。
- 阶段顺序错（先开花后发芽）、同一阶段内形态漂移（花瓣数忽多忽少），
  仍不通过，只重做该段。

## 参考图：变形主体只传当前阶段格，不传整张主画布

- 生长主体出场时，第一张参考图 = 当前阶段在主画布上的格裁剪
  （或该阶段的物品画布原图），不是整张主画布。
- 主画布仍是全集存档与验收总表：各阶段格全拼在上面，改版即整张升版，
  旧版作废；但生成时不把全量形态一次塞给模型。
- 物品特写同理：第三张参考图传当前阶段格裁剪。

## 场景状态链：同一地点，多状态

- 同一地点不同时间的状态，编号 S1-春、S1-夏、S1-秋（地点号不变，状态后缀变），
  每状态一张场景画布，地点同一性（同机位、同池塘、同朝向）写进文字稿。
- 场景验收只对照本状态的画布；状态间色调、固定元素变化不判漂移，
  判据是地点号相同 + 时间间隔写清。

## 缩时镜 timelapse：第三种镜头类型

- 镜头卡 `transition` 字段第三个取值 `timelapse`（另两个是 `continuous`、`cut`，
  见 `docs/SHOT_LANGUAGE.md`）。
- 定义：同机位、同构图，时间跳；首帧 = 同构图新阶段，不等于上一镜尾帧；
  免首尾帧相等规则、免 30 度规则（同机位是故意的）、免“切换须换主体/地点/
  景别”规则（换的是时间）。
- 转场配日期 / 间隔字幕，后期叠加（例如“第 1 天”“第 30 天”“第 90 天”），
  不进生成提示词。
- 判定：机位、构图与上一镜相同、时间间隔已写清，即为缩时镜；
  机位相同但没写时间间隔，是贴错标签的连续镜，不通过。

## 过程镜 process shot：转变本身必须有一镜（v3.14）

- 问题：v3.13 只修了“阶段怎么锁”，没修“过程谁来拍”。分镜是一段一个
  状态（卵就是卵、蝌蚪就是蝌蚪），发芽、孵化、开花这些转变本身没有分到
  任何一镜，掉进段与段的缝里；阶段锁定句写成“不演进到下一阶段”更把过程
  直接禁了。莲藕、蝌蚪两集 2026-11-15 实测：莲藕段 2 过程拍到了但没收住
  （首帧芽、中帧苞、尾帧花，越级溢出）；蝌蚪段 1 写明“不孵化、不出蝌蚪”，
  孵化过程整段缺席。
- 定义：过程镜是拍转变过程本身的镜头，动作的起—中—止就是转变：
  首帧 = 旧阶段末态，尾帧 = 新阶段初态（刚到达，不展开）。
  例如发芽：首帧藕在泥里 → 尾帧芽刚钻出水面（不长成苞、不开花）；
  孵化：首帧卵 → 尾帧蝌蚪破膜刚游出（不长腿）；开花：首帧花苞 →
  尾帧花刚打开（不结蓬）。
- 规则：每个相邻阶段交界处至少有一镜是过程镜；关键过程清单
  （发芽、孵化、开花、结果、蜕皮、变蛙……按题材列）写进文字稿，
  审计逐项核对，缺一镜即不通过，不进视频。
- 阶段锁定改措辞：写“不演进到下一阶段的完成态/展开态”，不写
  “不演进到下一阶段”。过程镜允许演进到新阶段的初态，不允许演进到
  新阶段的展开态——芽可以出水，不能长成花苞；蝌蚪可以破膜，不能长腿。
- 镜头卡：过程镜是缩时镜的一种，`transition` 取 `timelapse`，另加
  `process: {from_stage, to_stage}`（例如 `P1-S1 → P1-S2`），
  `from_stage`/`to_stage` 必须是同一生长主体的相邻阶段。
- 参考图：过程镜传旧阶段格裁剪 + 新阶段格裁剪两张（先后顺序 = 转变顺序），
  不传整张主画布；提示词写清起止两态。
- 验收：过程镜不适用“只对照本阶段”——首帧对照旧阶段图版末态，
  尾帧对照新阶段图版初态；尾帧演进到新阶段展开态是阶段溢出，
  首帧已是新阶段是过程没拍到（直接跳结果），两种都不通过，只重做该镜。

## 时间跳跃线：第 0 步的例外

- 生长 / 缩时题材的世界线用时间跳跃线：段间写清间隔（第 1 天 / 第 30 天 /
  第 90 天，或春 / 夏 / 秋），不再是“中途不换”；同一镜内时间不换，
  白天不能无故变夜晚（见 `docs/WORLD_TIMELINE.md`）。
- 时间跳跃线写进文字稿开头的时间线表，审计按表查，不按“时间不变”查。

## 非人主角：无人物时三视图可空

- 主角可以是生长主体 P1，不必是人。无出场人物时，故事 JSON 的 `characters`
  字段为空，`character_sheet` 可空，脚本跳过三视图硬门（见
  `scripts/check_story.py`）；主角登记为 P1，用生长序列代替三视图 + 表情行。
- 有园丁、路人等人物时，人物仍走三视图硬门，与 P1 并存。

## story.json 字段

```json
{
  "growth_sequences": [
    {"id": "P1", "name": "莲",
     "stages": [
       {"id": "P1-S1", "name": "藕", "item_sheet": "p1_s1.png"},
       {"id": "P1-S2", "name": "芽", "item_sheet": "p1_s2.png"},
       {"id": "P1-S3", "name": "花", "item_sheet": "p1_s3.png"}
     ]}
  ],
  "master_canvas": "master_canvas.png"
}
```

- `growth_sequences` 可选；有该字段时每阶段 `item_sheet` 文件必须存在，
  `master_canvas` 字段必填且文件必须存在，脚本 `check_story.py` 查。
- 镜头卡 `transition` 取值 `timelapse` 的镜，须在文字稿时间线表里有对应间隔。
- `shots` 字段可选（镜头卡列表）；有该字段时，带 `process` 的镜
  `from_stage`/`to_stage` 必须是同一生长主体的相邻阶段，且每个相邻阶段
  交界处至少有一镜过程镜覆盖，脚本 `check_story.py` 查；无 `shots` 字段的
  旧稿跳过，不追溯。
