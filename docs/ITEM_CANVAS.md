# 物品画布（v3.11 硬门）

## 为什么必须有图版

文字锁表拦不住视觉漂移。实测（2026-11-15《桃园三结义》）：文字稿写死“I2 陶酒碗三只”，
模型在段 4 仍把“盏”画成“碗”；段 2 案上多出水果盘和第二张案。
根因：物品只有文字，没有图；视频参考图只传尾帧或三视图，从不传物品图，
模型每段凭文字重发明一次形状。

**规则：关键物品没有图版，就不进视频，与三视图同级硬门。**

## 入选标准（满足任一即入选）

- 出现 ≥2 段；
- 被人物持有、穿戴、使用，或动作围绕它发生；
- 是剧情关键物（誓言、信物、武器、药、食物）；
- 用户点名。

其余物品只列文字锁表，不出图版。

## 每件物品一张图版，包含

- 正面 / 侧面 / 手中比例：同一物品三张小图，第三张必须与手同框，
  写清“与手掌同宽 / 约茶杯大小 / 约碗口两倍”等可比尺寸；
- 材质 + 色值：例如粗陶、哑光、灰值 #8A8A8A，不写“大概灰”；
- 状态：满 / 空、完好 / 破损、开 / 合，变化必须有画面动作支撑；
- 一句物品 DNA：形状、尺寸、材质、用途，一句话，之后每段提示词逐字复用，一字不改；
- 非此物清单：写清它“不是什么”，例如“盏不是碗，无大口、无深腹、无圈足过大”；
  只写肯定描述不够，否定清单是拦漂移的关键。

## 检查（关卡 2）

- 形状、尺寸与手的比例、材质、数量、状态，任一项与文字稿不符即不通过；
- 图版里无多余物品、无文字、无已知 IP 造型；
- 文件路径写进故事 JSON 的 `item_sheet` 字段，`scripts/check_story.py` 查文件存在，
  缺字段、路径为空、文件不存在，任一即不通过，不进视频；
- 用户点头后锁死，按季复用；改版即主画布升版，旧版作废。

## 生长序列物品（v3.13，变形主体）

见 `docs/GROWTH_SEQUENCE.md`。一个主体 P1，下挂多阶段图版 P1-S1、P1-S2……，
每阶段一张物品画布，同上要求，但有三处不同：

- 比例锚点：非手持主体不用“手中比例”，用固定参照物（池塘边、叶片、
  与人同框比大小），写清可比尺寸；
- 状态词表：完好 / 破损之外加生长态——发芽、抽叶、开花、结果、枯萎、落叶；
  生长态是正常状态，不判破损；
- 阶段 DNA 只描述本阶段形态，不写其他阶段；故事 JSON 用 `growth_sequences`
  字段登记各阶段 `item_sheet`，脚本查文件存在。

## 与主画布的关系

物品画布是单件的原图；主画布（见 `docs/MASTER_CANVAS.md`）把各件物品画布
拼成总图的一行。视频生成时传主画布，物品特写时另传主画布上该物品格的裁剪图，
不许凭文字重发明，也不许拿故事板格当物品参考。
