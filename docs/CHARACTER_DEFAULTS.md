# 人物形象默认值（v3.0）

## 问题

两个默认值漏了，模型就按自己的默认走——而模型的默认是西方的：

1. **语言没默认值。** v2.8 只锁了“一致性”（对话/旁白/字幕与目标语言一致），但目标语言本身的默认值写的是“按用户那句话的语言”。用户不指定时没有中文默认值，英文一句话就会出英文片。
2. **人物形象没默认值。** 三视图定型只写了“正面/侧面/背面 + 颜色卡 + DNA”，没写人物长什么样。没写时模型默认画西方长相——与 v2.7 文化问题同根（造型词无锚点，模型按西方补全）。

## 规则

**人物类剧集（有出场人物的），用户没有特别指定时，一律中文语言 + 东方人物形象。**

- 中文语言：目标语言默认中文。对话、旁白、字幕全是中文（见 `docs/LANGUAGE_LOCK.md`）。
- 东方人物形象：东亚面孔、黑色头发、黑色眼睛。写进角色表的“形象”栏和角色 DNA，之后每段提示词逐字复用。
- 只在两种情况改：用户明确指定其他语言（如“用英语讲”），或明确指定非中国背景（如“美国故事”“欧洲小镇”）。指定了就按指定的走，不按默认。
- 非人物类内容（风光、美食、汽车、产品等）不受这条管，按题材走。

## 怎么用

1. 第 1 步三视图定型时先写形象：没指定写默认（东方人物：黑发、黑眼睛、东亚面孔）；指定了写指定的。
2. 文字稿模板的角色表有一栏“形象”，每位出场人物必填（见 `templates/story_text_output.md`）。
3. 故事 JSON 的 `characters` 字段：每位人物写 `appearance`（形象一句话）；`character_origin` 不写时默认 `eastern`，写了其他值（如 `western`）时按写的值走。
4. 审计：`scripts/check_story.py` 查——`characters` 存在时，每位人物的 `appearance` 非空；`character_origin` 未写或为 `eastern` 时，`appearance` 必须含东方标记（黑发、黑眼睛、东亚、东方、亚洲、黄皮肤、中国面孔之一）；`character_origin` 明确写了其他值时不查标记。`characters` 字段缺失时跳过（v3.0 之前的旧稿不受影响）。

## 国家形象标志禁令（v3.0）

**画面内一律禁止出现国家形象标志：国旗、国徽、旗帜、国歌歌词、国家徽章类图案。**

- 不进文化锚点，不进角色服装，不进场景布置，不进提示词，不进画面。
- 制服、徽章、招牌、广场、集会场景最容易带进来，写镜头卡时逐项过：制服只写颜色和款式，不写徽章图案；招牌只写颜色和形状，不写旗帜；广场不写升旗、阅兵类场面。
- 审计：`scripts/check_story.py` 扫描文字稿的正文和对话，出现“国旗、国徽、旗帜、五星红旗、星条旗、国歌”即不通过；`checklists/continuity_audit.md` 核对每镜画面内无国家形象标志。
