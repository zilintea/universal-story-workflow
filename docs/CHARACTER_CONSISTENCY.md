# 人物一致性规范（v1.6 新增，硬规则，通用）

## 问题来源

多段视频是多次独立生成，每次都会重新画一遍角色，没有跨段的人物记忆。
只靠文字锁定表（例如“翠绿、头顶绿芽”）管不住生成端：颜色、体型、标志物最容易漂移，
侧面和远景漂得最厉害。本规范是通用流程的一部分，**不写死任何具体人物、场景、物品、颜色、IP 名称**。
所有具体内容只出现在本集的文字稿和对应 IP 插件里。

## 原则

1. **三视图先定型，故事板和视频都只能沿用，不重新发明外形。**
2. **角色 DNA 一句话，逐字复用，一字不改。**
3. **每段成片帧都要对照三视图验收，漂移即不通过，重生成。**
4. **文字提示词只能降低漂移，不能保证零漂移。** 这一点必须 upfront 说明：
   生成工具支持“传三视图当参考图再生成视频”时，用参考图锁定；
   不支持时，用本规范的 DNA 复用 + 逐段验收 + 重生成兜底。
5. **形象默认值（v3.0，见 `docs/CHARACTER_DEFAULTS.md`）：人物类剧集用户没特别指定时，形象一律东方人物（东亚面孔、黑发、黑眼睛），写进角色表“形象”栏和 DNA；用户明确指定其他背景时写指定的。**
6. **三视图硬门（v3.1）：三视图文件路径写进故事 JSON 的 `character_sheet` 字段，`scripts/check_story.py` 查文件存在，缺字段、路径为空、文件不存在，任一即不通过，不进故事板。生成视频的人物参考图必须是三视图，不许拿 9 格故事板当人物参考（故事板是 9 个镜头拼图，抽不出人脸）；故事板生成时也要传三视图当参考图；第一段试点没有上一段尾帧时用三视图当参考图。**

## 第 1 步：三视图定型（故事板之前，视频之前）

每位出场人物一张角色画布，内容：

| 项目 | 写法（占位符，换 IP 时只填这里） |
|---|---|
| 三视图 | 正面 / 侧面 / 背面，同一张图，三张前后一致 |
| 表情行 | 至少 5 个表情（笑、委屈、得意、困、惊讶），与三视图同一个人 |
| 颜色卡 | 主色 [色值]、次色 [色值]、标志物色 [色值]，各写色值，不写“大概绿” |
| 体型比 | 与主角的相对高度 [例如：主角 1.0，本角色 2.0]，画在图里 |
| 标志物清单 | 每件标志物 [名称]：必须出现、不能缺、不能换、不能换色 |
| 禁项 | [本角色不能出现的造型、颜色、道具] |
| 角色 DNA | 一句话：[体型]、[主色]、[标志物]、[服装/道具]，之后每段提示词逐字复用 |

检查（任一项不过，三视图不通过，不进故事板）：
- [ ] 正面、侧面、背面是同一个人，无多手多脚
- [ ] 颜色卡三色与三视图一致
- [ ] 每件标志物三视图里都在，且位置、颜色一致
- [ ] 体型比与文字稿一致
- [ ] 无文字、无已知 IP 造型

## 每段视频提示词：角色 DNA 逐字复用

- 每段提示词里，出场人物的角色 DNA 必须**逐字**出现，一字不改，不换说法、不缩写、不省略。
- 颜色、体型、标志物、比例四项，每段都必须出现，缺一项就不生成。
- 不许每段换一种写法描述同一个人：换写法就是换一个人。
- 机器检查：`scripts/character_check.py`，DNA 未逐字出现即不通过。

## 每段验收：对照三视图核对（成片帧为准）

每段抽 2 秒帧和 5 秒帧，对照三视图逐项核对：

| 核对项 | 通过标准 | 不通过例子 |
|---|---|---|
| 颜色 | 主色、次色与颜色卡一致 | 主色变深、变浅、变色 |
| 体型 | 身高、胖瘦、比例与三视图一致 | 变长、变圆、变高、腿变长 |
| 标志物 | 每件标志物都在，位置、颜色一致 | 标志物缺失、换色、换位置 |
| 服装/道具 | 与三视图一致 | 帽子换色、围巾变围裙、凭空多出道具 |
| 比例 | 与其他出场人物的相对高度一致 | 本应 2 倍高，拍出来差不多高 |

任一项不通过，该段不通过，重生成，不接受“剧情对了就行”。

## 连续两次漂移：改拍法，不硬烧积分

同一段连续两次因人物漂移不通过，停止原提示词重生成，改用更安全的拍法：
- 只拍正面 / 四分之三面，不拍侧面和背面
- 人物居中、大景别，减少模型发挥空间
- 标志物放在画面中心，先拍标志物特写再切全景
- 改拍法后仍不通过，降级为静态三视图 + 旁白，或等用户决定，不继续烧积分重生成。

## 与其他审计的关系

- 人物一致性是第 4 步五审计里的独立一项，与安全、逻辑、语言、剪辑并列。
- 剪辑审计（`scripts/edit_check.py`）管转场和物品连续，人物审计（`scripts/character_check.py`）管外形和标志物，
  两张表都要通过才进交付。
- 物品连续仍按 `docs/CONTINUITY.md`：物品状态变化必须有画面动作支撑，禁止瞬移。
