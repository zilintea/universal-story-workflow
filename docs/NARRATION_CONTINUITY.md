# 旁白连续性（v1.9 新增）

> 问题（用户 2026-11-05）：旁白句子跳跃。根因：语言审计把旁白压成教学句，
> 每句一个独立短句，主语、时间、地点每句都换。
> 深圳片早有定论：旁白必须持续讲解，句子跨镜不断，整段录不分镜。
> 本文件把那条定论写回通用技能。

## 两条轨，分开写

| 轨 | 写法 | 规则 |
|---|---|---|
| 旁白轨 | 一整段连续自然语言，按时间顺序讲 | 主语、时间、地点不跳；句子之间用“于是、这时、到了、接着”接；剪辑点落在句子中间，不落在句号上；整段录，不分镜录 |
| 教学轨 | 词汇、句型、跟读句，单独放 | 词汇重复靠跟读和复习，不靠把旁白拆碎；对话短、重复、有用，句长上限读语言档案 |

## 旁白连续性审计（第八审计的一部分）

每相邻两句旁白，必须同时满足：

1. 时间连续：上一句的结尾时间 = 下一句的开头时间，或有明确的时间词过渡
   （“天还没亮 → 到了早上”，不许“夜里 → 太阳很高了”中间断档）。
2. 地点连续：上一句的地点 = 下一句的地点，或有明确的移动动作过渡
   （“出了南山 → 走在雪路上”，不许地点无故瞬移）。
3. 主语连续：上一句的主语 = 下一句的主语，或主语交接有动作
   （“他赶着牛车 → 牛走得很慢”，不许主语每句换一个人）。
4. 三者至少两项连续；三项全断，该句不通过，重写，不进视频。
5. 禁止：每句一个独立短句、每句换主语、每句换时间、每句换地点、
   旁白里塞词汇表、旁白总结主题（主题由结尾画面给，不由旁白说）。

## 改写示例（同一段意思）

旧（跳跃，不通过）：
> 他卖炭。雪很大。牛累了，人饿了。

新（连续，通过）：
> 天还没亮，他就赶着牛车出了南山，雪下了一夜，路上的冰辙被车轮压得发亮，
> 牛走得很慢，他也不催，只跟着车慢慢往城里走。

## 脚本

`scripts/check_narration.py`：输入旁白文本（每句一行），查：
- 每句是否过短（中文 <6 字且连续 3 句以上 → 判跳跃）
- 相邻两句是否共享时间词/地点词/主语词（用锁定表里的词查，不靠模型猜）
- 是否出现词汇表式罗列（同一句里塞 ≥3 个目标词且无动词连接）
好旁白通过，坏旁白拦下。词表只按本集锁定表查，不写死任何具体词。
