# 世界空间 + 故事时间线 + 逻辑结构

## 世界空间（宏大叙事的基础，写一次，全季复用）
- 世界地图：一张文字地图，每个地点写清方位（在谁的东/西/南/北/上/下）、相对位置、距离、入口出口、相邻地点、连通路线（例如：[场景 D] 在[场景 A]后面；[场景 E] 在[场景 D]顶；[场景 A] 东边约 200 米是[场景 B]）。地点落在地图上的固定位置，不是按故事顺序排的队列；故事顺序可以变，地图不变
- 空间规则：每个地点只能从相邻地点到达，不能瞬移；每个地点有固定元素、主色调、光线（见 CONTINUITY.md）
- 世界规则：这个世界里什么可以发生、什么不可以发生（例如：本集世界无人类、无反派，麻烦只来自误解和粗心；本集角色会说话，但不会开车、不会打电话——具体规则只按本集世界观写）

## 故事时间线（完整，不许悖论）
- 全季时间线：季弧（本季主角学会什么）→ 集弧（本集学会什么）→ 幕时间（本集内的时间顺序）
- 每集时间线表：事件 | 时间（上午/下午/晚上）| 地点 | 人物 | 结果
- 角色时间线：年龄、学会的技能、拥有的物品，随集数增长，不倒退（除非剧本明确写了“忘记/丢失”这个动作）
- 时间一致性检查：上一集学会的技能，下一集可以用；上一集丢失的物品，下一集不能无故出现；白天不能无故变夜晚

## 逻辑结构（严谨，三层）
- 季逻辑：季主题一句话，季终 payoff 必须在季首埋伏笔
- 集逻辑：集主题一句话，因果链，伏笔-payoff 对照表（见 PLOT_ARRANGEMENT.md）
- 幕逻辑：每幕起因 = 上一幕结果，动作匹配，物品/场景连续（见 CONTINUITY.md、EDITING_STANDARDS.md）
