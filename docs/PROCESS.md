# 流程环节规范（v1.8 新增，硬规则，通用）

## 为什么要补这一块

v1.7 之前，工作流只会讲“一个目标、一个反转”的故事，不会讲“一步一步做一件事”的流程。
做一道菜、做手工、搭积木、洗衣服，都是流程型剧集：**顺序错了，东西就毁了；步骤漏了，
成品就出不来；危险步骤不写安全做法，孩子照着学就危险。**

本规范是通用流程的一部分，**不写死任何具体菜、具体手工、具体步骤**。
所有具体内容只出现在本集的文字稿里。红烧鱼只是示例，换成做汤圆、搭积木、洗衣服，
流程不变。

## 流程型剧集的定义

- 本集有一个明确的成品：[成品名]，例如一道菜、一件手工、一个干净的房间。
- 成品由 N 个步骤做出来，步骤有固定顺序，换顺序就失败或危险。
- 每一步都有：动作、用的材料/工具、上一步留下的状态、这一步做完的状态。
- 本集的“反转”不是凭空变出来的，是某一步做对了、做错了、或者用户的一个创意点子，
  让成品变好了。

## 流程锁定表（故事开始前写死）

| 项目 | 写法（占位符，换流程时只填这里） |
|---|---|
| 成品 | [成品名]，最终状态 [例如：鱼熟了、盘子干净了] |
| 材料清单 | 每种材料 [名称]、[用量]、[初始状态]，用完即走，不凭空出现 |
| 工具清单 | 每种工具 [名称]、[用途]，危险工具标 [危险：烫/锋利/火/电] |
| 步骤表 | 每步 [序号]、[动作]、[用材料/工具]、[前置条件]、[做完的状态]、[时长]、[安全做法] |
| 创意点 | 用户的创意 / 创新 [一处，最多 1 处]，写清它改了什么、没改什么 |

## 流程约束（硬规则，任一条不过不进视频）

1. **顺序锁死**：步骤按序号来，1→2→3，不能跳、不能倒、不能并。
   上一步没做完，下一步不能开始。
2. **前置条件**：每一步的“前置条件”必须由前面步骤的“做完状态”或初始材料满足，
   不能凭空满足。例如“下锅煎”要求“油热了”，油没热就不能煎；
   “加调料”要求“鱼煎好了”，鱼没煎好就不能加。
3. **材料不瞬移**：材料只能在画面里被拿起、放下、切开、倒进、吃掉，
   不能上一镜在桌上，下一镜无故在锅里；用量不能凭空变多。
4. **成品不凭空出现**：成品只能由最后一步做出来，中间任何一镜都不能提前出现成品。
5. **危险步骤必须有安全做法**：标了烫、锋利、火、电的步骤，必须写清安全做法，
   且必须是大人/伙伴在场、或主角只做安全的那一半（例如：大人掌勺，主角只放葱花；
   刀只由大人拿，主角只摆盘）。孩子独自做危险步骤，一票否决。
6. **创意点最多 1 处，且不能破约束**：用户的创意、创新是鼓励的，但必须写清
   它改了什么、没改什么。创意可以改造型、改摆盘、改一句台词、加一个笑点，
   不能改步骤顺序、不能省掉关键步骤、不能改成品的最终状态、不能绕过安全做法。
   创意点要单独列在流程锁定表里，审计时单独查。

## 流程审计

`scripts/check_process.py` 按流程 JSON 检查：
- 步骤序号连续、无跳号、无倒序
- 每一步的前置条件都被前面的步骤满足
- 每种材料、工具都先在清单里出现过，才在步骤里用
- 成品只在最后一步出现
- 危险步骤都有安全做法
- 创意点 ≤1 处，且声明了“没改什么”
任一项不过，改流程表或改剧本，不生成视频。

## 与其他审计的关系

- 流程审计是第 4 步的独立一项，与安全、逻辑、语言、剪辑、人物、场景并列，
  只做流程型剧集时查，非流程型剧集不查。
- 安全审计（`docs/CHILD_SAFETY.md`）管“能不能学”，流程审计管“顺序对不对、成品出不来”，
  两张表都要通过才进交付。
- 人物、场景、物品连续仍按 `docs/CHARACTER_CONSISTENCY.md`、
  `docs/SCENE_CONSISTENCY.md`、`docs/CONTINUITY.md` 查。

## 全面审计 v1.7 → v1.8（本次补齐的缺口）

| 维度 | v1.7 | v1.8 |
|---|---|---|
| 故事逻辑 | 有因果链、伏笔 | 不变 |
| 流程顺序 | 没有，步骤可跳、可倒 | 新增流程锁定表 + check_process.py |
| 材料/工具 | 只有物品连续，没有用量和初始状态 | 新增材料、工具清单，用量和状态锁死 |
| 流程安全 | 只有通用安全线，没有危险步骤的安全做法 | 危险步骤必须有安全做法，大人/伙伴在场 |
| 用户创意 | 没有位置，创新会被当成偏差拦下 | 新增创意点 1 处，单独审计，鼓励创新但不破约束 |
| 长篇剧集 | 季弧、词汇复习有了 | 不变，流程型剧集的季表也要过 check_season.py |
| 语言 | 语言档案有了 | 不变，流程步骤里的对话、旁白仍按语言档案走 |
| 人物/场景 | 三视图、场景画布有了 | 不变，流程步骤里的人物、场景仍按三视图和场景画布查 |
