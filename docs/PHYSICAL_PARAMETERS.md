# 物理参数库（v3.31）

> 情绪词改写成物理参数的词库。不写“很顺滑”“很震撼”“很美”，一律改写成物理量。
> **按内容选参数**：先定本段的内容类型（下表），再从对应类型里挑，不跨类型硬套
> （儿童故事不用冷调侧光，产品不用尘土飞扬）。模板里的“物理参数”段按这里写；
> 运动、光、形变、对焦四类至少各写一条，缺一类即提示词没写完。
> 每个参数写进节点时要绑定具体对象（“画笔 ASMR 级顺滑运动”，不写“很顺滑”）。

## 通用（任何内容都可用）

- 运动：ASMR 级顺滑物理运动、匀速直线运动、自由落体、弹性回弹、惯性滑行、匀速推近
- 光：丁达尔体积光、平行光束、漫反射、镜面反射、暖金逆光、冷调侧光
- 形变：纸质地图般的卷曲折叠、橡皮泥般的挤压回弹、布料般的垂坠摆动、金属般的弯曲不断
- 对焦 / 景深：微距移轴、极浅景深、焦点锁死、背景虚化、前景虚化、深景深
- 质感：毛毡哑光、黏土哑光、玻璃反光、金属拉丝、皮革纹理、陶瓷釉面
- 速度：每秒 X 厘米、0.5 秒内完成、骤然加速、匀速、戛然而止、缓慢、瞬间

## 选参数规则

- 先定内容类型（上表），再从对应类型里挑；不跨类型硬套。
- 运动、光、形变、对焦四类至少各写一条；缺一类即提示词没写完。
- 质感反差只在有比例 / 质感对撞的场景用（产品微距、微缩、食物、自然），普通场景不加，不硬套。
- 每个参数写进节点时绑定具体对象与动作（“画笔 ASMR 级顺滑运动”“镜片镜面反射”），不写孤立的形容词。
- 写完逐个形容词自问‘这是物理量吗’，不是就重写（见模板“物理参数”段）。
