# 世界空间线（v1.9 第 0 步，先画地图再写故事）

> 问题：先写故事再补场景，场景跟着剧情现想，每集换场景、换路线。
> 改法：第 0 步先整理世界空间线，再写故事。中国典故、美国故事都走同一张表，
> 只是填的内容不一样，表本身不写死任何一个故事的名字。

## 第 0 步输出（一张表，三项）

1. **地点线**：地点按顺序排成一条线，不许跳。
   如：[地点 A] → [地点 B] → [地点 C]，每个地点写死固定元素、主色、光线、默认机位。
   场景切换必须有路线，中间要有走路/飞行/赶车的过渡镜，不许瞬移。
2. **时间线**：白天还是夜里，晴天还是雪天，时间从几点到几点，中途不换；
   时间流逝只用同机位叠化，不用硬切。
3. **世界规则**：这个世界里什么可以、什么不可以。
   如：没有法术的世界不能突然出现法术；有法术的世界要写清法术的代价。

## 适用

- 中国典故：先从原典里抽地点线、时间线、规则，再写故事，不编造原典没有的地点。
- 美国故事：同上，地点、时间、规则按原故事写，不套中国场景。
- 原创 IP：按季锁死世界地图（≤6 个主场景），每集最多加 1 个新场景。

## 与旧文件的关系

- `docs/WORLD_TIMELINE.md` 是季级世界地图（季弧、时间线）；
- 本文件是集级第 0 步（本集的地点线、时间线、规则），写在文字稿开头，
  故事、镜头、场景三者都以它为准，故事中不改。
