# 世界空间线（v1.9 第 0 步，先画地图再写故事）

> 问题：先写故事再补场景，场景跟着剧情现想，每集换场景、换路线。
> 改法：第 0 步先整理世界空间线，再写故事。中国典故、美国故事都走同一张表，
> 只是填的内容不一样，表本身不写死任何一个故事的名字。

## 纠正（v2.6）：世界空间线是一张地图，不是一条队列

以前的描述是错的：“地点按顺序排成一条线，不许跳”——把世界空间线写成了
按故事顺序排的地点队列。**正确的描述：世界空间线是一张世界地图。**
地点落在地图上的固定位置，有方位、相对位置、距离、入口出口；
地点之间由路线连通，故事只能沿着地图上的路线移动，不能瞬移。
**故事顺序可以变，地图不变。** 同一集里可以先去河湾再回小屋，
只要走的是地图上的路；不能因为剧情需要，就从一个地点直接切到地图上
不相邻的另一个地点。

## 第 0 步输出（一张地图 + 时间线 + 世界规则）

1. **世界地图（空间布局，不是顺序）**：每个地点写清——
   方位（在谁的东/西/南/北/上/下）、相对位置、距离、入口/出口、
   相邻地点、连通路线。再写死每个地点的固定元素、主色、光线、默认机位。
   例：厨房小屋在山脚；柿子树在小屋后面；河湾在小屋东边约 200 米；
   云岛在柿子树顶，从树干爬上去。
   移动规则：只能去相邻地点，沿着路线走；切换地点要有走路/飞行/赶车的
   过渡镜；不许瞬移。
2. **时间线**：白天还是夜里，晴天还是雪天，时间从几点到几点，中途不换。
   时间线只写时间，不写转场方式；时间流逝用什么转场，见剪辑标准。
3. **世界规则**：这个世界里什么可以、什么不可以。
   如：没有法术的世界不能突然出现法术；有法术的世界要写清法术的代价。

## 适用

- 中国典故：先从原典里抽世界地图、时间线、规则，再写故事，不编造原典没有的地点。
- 美国故事：同上，地点、时间、规则按原故事写，不套中国场景。
- 原创 IP：按季锁死世界地图（≤6 个主场景），每集最多加 1 个新场景。
