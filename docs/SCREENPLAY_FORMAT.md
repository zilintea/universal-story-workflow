# 拍摄剧本格式（v3.17 剧本输出模式）

## 输入与输出顺序（v3.18 剧本先行）

用户给出一句话或一段剧情 → 先按本格式出拍摄剧本 `screenplay.md`（第一交付物，
关卡 1：用户审剧本）→ 再从剧本里定人物、关键物品、场景：人物出三视图、
关键物品出物品画布、场景出场景画布，三者拼成主画布（第二交付物，关卡 2：
用户对照剧本审画布）→ 确认后产视频。

人物、关键物品、场景的清单从剧本里抽，不先于剧本定：剧本里有的人物、
关键物品、场景，画布里必须有；画布里不许出现剧本外的人物、物品、场景。
剧本改了人物、物品、场景，画布跟着改，改版记进剧本附录。

## 定位

视频脚本的唯一交付物是**拍摄剧本 `screenplay.md`**。文字稿（`story_text.md`）、
镜头卡（`shot_cards.md`）、故事板文字版是工作底稿，用户审的是剧本，不审散文件。
镜头语言（每镜的首帧、动作、尾帧、转场）写进剧本，不再单独立镜头语言文件。

根因（2026-11-15《松林夜战》）：脚本输出散在四处——文字稿、镜头卡表格、
故事板、画布——转场问题（落地瞬移、景别猛跳、刀光没成镜、颜色漂移）没法在一处
审出来。用户定：改标准电影剧本格式，场次 + 动作 + 机位。

## 格式

```
# 《片名》拍摄剧本

片长 X 秒 · N 场 · M 镜 · 画幅 · 风格 · 对白/无对白
（按标准电影剧本格式输出）

## 人物
- 角色名：外貌、服装（色值）、武器/物品、打法/性格，一行一个。

## 场景
- 场景名：地点要素、时间、光线、色调，一行一个。

---

场 1 外·地点·时间段（0:00–0:XX）

场景描写一两句（只写画面，不写心理、不写故事背景）。

【镜 1 · 段 1 · 0:00–0:05 · 景别 · 机位 · 运镜】

动作正文（现在时，只写看得见的动作与画面，一镜一个动作节拍）。

首帧：画面定格描述（人物位置、服装色值、人数）。
尾帧：画面定格描述（人物位置、服装色值、人数）。

接上镜（连续）

【镜 2 · 段 1 · 0:05–0:10 · 景别 · 机位 · 运镜】

动作正文。

首帧：接上镜——与上镜尾帧同一画面。
尾帧：画面定格描述。

切至

【镜 3 · 段 2 · 0:10–0:15 · 景别 · 机位 · 运镜】

动作正文。

首帧：画面定格描述。
尾帧：画面定格描述。

---

## 附录：锁表
- 人数：全片人数与每镜人数。
- 武器/物品：数量与出场镜号。
- 颜色：人物服装色值、光色方向。
- 地点：是否换场、地面/环境固定要素。
- 段位：段 = 哪几镜；段边界即镜边界，不另加转场。
```

## 规则

- **场次标题**：`场 N 内/外·地点·时间段（起–止时间码）`；同一地点同一时间是一场，
换地点或换时间才开新场；时间码全片连续。
- **镜头行**：`【镜 N · 段 X · 起–止时间码 · 景别 · 机位 · 运镜 · 节奏】`；
景别/机位/运镜用 `docs/SHOT_LANGUAGE.md` 的短码（中文写全称，如 全景、低机位、升降；
v3.19 运镜库已并入该文件，选镜按“按场景需求选镜”一节调用）；节奏快/中/慢，
新稿必填，默认 中，旧稿可空。
- **动作正文**：现在时，只写看得见的动作与画面；不写心理活动，不写故事背景，
不写“竟然”“居然”这类表意外的副词；速度词（骤然、猛地、瞬间、闪电般）快节奏镜
必须写；中 / 慢镜一镜只写一个动作节拍，快镜一镜可写 2–3 个连发动作节拍
（beats 字段写个数）。
- **首帧/尾帧**：每镜必写；首帧写清人物位置、服装色值、人数；尾帧同上。
连续镜的首帧写“接上镜——”加尾帧原文；切换镜的首帧写本镜自己的开场。
- **转场行**：两镜之间必有一行，只四种——`接上镜（连续）`、`切至`、`叠化`、`淡入/淡出`；
连续 = 下镜首帧等于上镜尾帧；切换 = 同一时刻同一地点、只换景别（主体/地点/景别
三者至少换其一）；叠化/淡入淡出只用于时间或地点真的变了。
- **对白**：有人物说话时，动作正文后另起行，人名居中（行首空四格），下一行写台词；
台词语言 = 目标语言。无对白的片子不写对白行。
- **旁白**：旁白不进动作正文，另起行写 `旁白：……`；旁白文本与字幕一致，见 `story_text.md`。
- **附录锁表**：剧本末尾必有，人数、武器/物品数量与出场镜号、颜色、地点、段位五项；
生成提示词按锁表写，不另发明。
- **段位**：视频按段生成（每段约 10 秒），段边界必须落在镜边界上，不许一段切在镜当中；
动作 / 打斗场面每段可 3–4 镜，每镜 2–3 秒，文戏每段 2 镜、每镜 5 秒。
