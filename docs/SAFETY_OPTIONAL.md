# 安全说明文件（可选说明，不参与审计）

> v2.1 修正（用户定）：这里的“安全选项”指的是技能里的**说明文件**，
> 不是工作流里的一道关卡。本文件和 `docs/CHILD_SAFETY.md` 只是说明文件，
> 默认不加载，不参与审计，不当关卡，不一票否决。
> 本技能是所有场景通用的版本，主流程不预设少儿、不预设安全审计。

## 这是什么

- `docs/CHILD_SAFETY.md`：少儿安全线 8 项的说明文件，供人查阅。
- 本文件：说明上面那份文件是什么时候可以查阅。
- 两份都是说明文件，不是模块，不是审计步骤，不是门禁。

## 什么时候可以查阅

用户明确说受众是小朋友 / 少儿 / 儿童 / 启蒙，或用途是语言教学，
或明确说“按少儿标准看一下”时，可以把 `docs/CHILD_SAFETY.md` 当参考翻一遍，
作为文字稿的补充意见。查阅后是否改故事，由用户定，不自动打回。

## 默认状态

- 不加载，不查阅，不审计。
- 成人向、历史、神话、现实题材按题材本身的逻辑写，不按少儿标准改写。
- 安全说明文件不加载时，仍保留一条底线：不生成违法内容；
  其余内容判断按用户的一句话提示和题材本身走。
