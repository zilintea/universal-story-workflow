# 场景模板（v2.9）

## 来源与写法

改编自 woodfantasy/seedance-shot-design《references/scenarios.md》（MIT-0，20 个场景 + 3 个新增）。不是原文搬运：每个场景按本仓库的语言重写，只保留“题材 → 风格 + 镜头要点”，去掉 Seedance 平台专属的界面操作（延长、编辑、绿幕、多镜头混剪等），改成我们自己的接法（镜头卡、尾帧锁定、分段）。风格一律用本仓库 `data/styles/` 里的 id；品牌名只作选择简称，不进提示词。

用法：用户一句话提示命中某个场景的信号词时，`scripts/suggest_style.py` 在风格建议之外再输出该场景名；镜头卡按本节的“关键点”写。

**硬规则（v2.10）：有场景必读必用。**`suggest_style.py` 输出了 `scenario` 时，必须读对应节，把关键点写进镜头卡，并在文字稿“场景模板”栏登记（场景名 + 至少 2 条已用关键点）；没命中场景时写“无场景”，`story.json` 的 `scenario` 字段写 null。`scripts/check_scenario.py` 查：缺字段、场景名不在 23 个里、登记不足 2 条、内容型场景镜头卡关键词命中不足 2 组，任一即不通过，镜头卡没写完，不进视频。结构型场景（十长视频、十七改编、十八延长、十九补全、二十多帧、二十二混剪）只查字段与登记，不查关键词。

## 一、电商产品广告

- 信号词：广告、产品、带货、种草
- 主推 liveaction，备选 pixar3d
- 核心参数：9:16 或 16:9，5–10 秒；Orbit 环绕 + 微距特写 + 主光打亮产品
- 关键点：产品居中旋转展示，纯黑/纯白背景，轮廓光勾勒；微距拍表面质感（金属反光、玻璃折射、液体流动），浅景深；最后拉远揭示使用场景
- 接法：按产品写材质清单进镜头卡；画面内不写字，价格/卖点走后期

## 二、仙侠/奇幻动画

- 信号词：仙侠、奇幻、修真、西游、神话、封神
- 主推 guoman3d，备选 disneypixar3d（喜剧/合家欢时）、inkwash（诗意时）
- 核心参数：16:9 或 2.35:1，10–15 秒；航拍穿越 + 摇臂升降 + 推轨穿门
- 关键点：3D国漫CG质感或水墨粒子；金青/暗紫/仙白/玄黑；丁达尔光束穿云，灵力粒子漂浮，仙气弥漫；云海仙境、悬崖古寺、飞天衣袂
- 接法：文化锚点必写（服饰/器物/地貌五类）；法术场面写清“灵力从哪来、到哪去”，不写空泛特效

## 三、短剧/对白场景

- 信号词：短剧、对白、对话、吵架、表白
- 主推 liveaction，备选 pixar3d
- 核心参数：16:9 或 9:16；演员调度三要素：站位、视线、动作动机
- 关键点：对白与画外音分开控制——对白是角色说的，旁白是讲背景和心情的，不重复同一句话；运镜绑叙事动机（推近 = 情绪逼近，拉远 = 关系疏远）；情绪转变要写清触发点
- 接法：对话与旁白分轨（本仓库已有）；每句对白绑说话人，不写“众人说”

## 四、美食特写

- 信号词：美食、做饭、吃播、菜谱、烹饪
- 主推 liveaction，备选 pixar3d
- 核心参数：9:16 或 16:9，5–8 秒；微距 + 环绕 + 俯拍
- 关键点：食物油光、蒸汽、酱汁流动的物理模拟；慢镜头拍关键动作（切、炸、拉丝），食材碰撞溅起液体/粉末；声音写 ASMR（切割声、油炸声）
- 接法：流程类故事走 `docs/PROCESS_EPISODE.md` 六条硬规则；热锅/热油只由成人操作

## 五、音乐MV/卡点

- 信号词：MV、卡点、音乐、舞蹈、节奏
- 主推 liveaction，备选 cel2d
- 核心参数：16:9 或 9:16，10–15 秒；Speed Ramp + Whip Pan + 节奏剪辑
- 关键点：音画同步——每个节拍命中一个动作；频闪灯光/舞台色光轮换/剪影逆光；慢动作 + 节拍命中高潮
- 接法：配乐先定 BPM 和节拍点，镜头卡按节拍写时间戳；本仓库的旁白时长预估不适用 MV（音乐轨另算）

## 六、一镜到底

- 信号词：一镜到底、长镜头、不切
- 主推 liveaction，备选 pixar3d
- 核心参数：16:9，10–15 秒；Steadicam/Gimbal 全程不切
- 关键点：提示词明确写“一镜到底，全程不切镜头”；镜头从起点出发，穿过空间 A（事件 A），转向空间 B（事件 B），最后推近聚焦终点；全程流畅，无跳切
- 接法：本仓库的分段结构（N = D ÷ 10）不适用一镜到底——D ≤ 30 秒时整段一次生成；超过 30 秒按“空间交接”拆段，交接点写清人物位置与朝向

## 七、微距特效/万物生长

- 信号词：微距、生长、绽放、水滴、慢镜头
- 主推 liveaction，备选 pixar3d
- 核心参数：16:9，5–10 秒；微距 + 慢镜头 + 延时
- 关键点：浅景深散景，微观物理（水滴碰撞、花朵绽放、冰晶形成），慢镜头 120fps 捕捉细节，微观粒子在光线中漂浮
- 接法：单过程单镜头，不贪多；生长类写清起点状态和终点状态

## 八、汽车大片

- 信号词：汽车、车、赛车、公路
- 主推 liveaction，备选 pixar3d
- 核心参数：2.35:1 或 16:9，10–15 秒；跟拍 + 航拍 + 仰拍低角度
- 关键点：金属光泽、轮胎烟雾、路面反射；航拍跟拍壮阔场景，车漆反射天光；仰拍掠过，Speed Ramp 慢转快；golden hour 侧逆光打亮车身线条
- 接法：品牌/车型写清进镜头卡，不写品牌名进风格；车速感靠背景拖影，不靠镜头乱晃

## 九、自然风光/航拍

- 信号词：风光、航拍、山水、自然、旅行风光
- 主推 liveaction，备选 ghibli
- 核心参数：16:9 或 2.35:1，10–15 秒；航拍缓慢推进 + 摇臂升降 + 延时
- 关键点：自然光、大气透视、体积云；高空缓慢推进，晨雾中景观逐渐显现；降落到水面/花海/山脊，层次切换；自然元素特写（瀑布水雾、花海摇曳），体积光穿透大气；环境音（风声、水声、鸟鸣）
- 接法：地貌写进文化锚点/世界地图，不写“美丽风景”这种空词

## 十、长视频场景化策略（30–180 秒）

- 信号词：长视频、电影、长片、纪录片
- 主推：按题材走建议表（本场景只定结构，不定风格）
- 核心策略：31–180 秒连续叙事优先一次成片式结构（角色/场景/道具 Bible + 故事概述 + 时间轴分段）；恰好 30 秒且要精确控制时用标准分段；只有原视频需要保留时才延长
- 关键点：只在三种情况拆段——总时长超 180 秒；需要分集审批或独立返修；创作上必须用不同生成路线。拆段时定义交接状态：人物位置与朝向、动作动量、道具所有权、镜头方向、光线和音频尾部，避免下一段状态重置
- 接法：对应本仓库 `docs/FORMATS.md` 的剧集/电影规模 + `docs/WORLD_MAP.md` 的世界地图；本仓库的分段（N = D ÷ 10）就是拆段时的交接状态写法

## 十一、游戏 PV / 角色出场

- 信号词：游戏、PV、角色出场、登场、技能
- 主推 pixar3d，备选 cel2d（二次元变体）
- 核心参数：16:9 或 2.35:1，10–15 秒；Orbit 环绕 + Speed Ramp + 推近 + 定格
- 关键点：黑屏 + 标志性音效，微弱粒子汇聚；Speed Ramp 从慢到快，标志性动作/武器出鞘，环绕 180°，技能特效爆发；推近锁定面部特写（眼部特效/瞳孔变化）；定格 Pose，全身居中，粒子收束
- 接法：角色三视图先锁定（本仓库 v1.6）；技能光效写清颜色和来源，不写“炫酷特效”

## 十二、恐怖惊悚片段

- 信号词：恐怖、惊悚、悬疑、鬼、吓人
- 主推 liveaction，备选 cel2d（只在动画向时）
- 核心参数：16:9 或 2.35:1，8–15 秒；Slow Push In + Static 长镜头 + 突然 Whip Pan
- 关键点：**负空间控制**——画面大量黑暗/留白（暗部占 70%+），仅有微弱光源；低调打光，低饱和暗色调；不安的征兆（物体微动、影子变化、灯光闪烁），镜头不动或极缓推进，制造窒息等待感；惊吓瞬间 Whip Pan/Snap Zoom/突然出现，声音冲击；收尾回到静默，余韵恐惧；音效极致安静（呼吸/心跳）→ 突然尖锐音效/低频冲击
- 接法：恐怖靠打光和负空间，不是靠风格卡——镜头卡必须写清光源位置和暗部占比；本仓库安全线不拦恐怖题材，但儿童模式不接恐怖

## 十三、旅行/城市氛围片

- 信号词：旅行、城市、Vlog、街头、氛围
- 主推 liveaction，备选 ghibli
- 核心参数：16:9（电影感）或 9:16（Vlog），10–15 秒；POV 街景 + Gimbal 跟拍 + 延时 + 航拍
- 关键点：蒙太奇碎片拼贴，生活化自然光；航拍/摇臂下降看天际线；街景 POV 穿过市场/小巷/人群，在地文化细节微距（招牌、食物、工艺、建筑纹理）；人与城互动（当地人动作/表情/手部特写），自然光 + 浅景深，手持微晃纪实感；Golden Hour 收束，渐入暖调，留白收尾；城市环境音拼贴
- 接法：地点写进世界地图；在地细节写进文化锚点，不写“异域风情”这种空词

## 十四、宠物/萌系

- 信号词：宠物、猫、狗、萌、治愈
- 主推 liveaction，备选 pixar3d
- 核心参数：9:16 或 1:1，5–10 秒；与动物**平视机位** + 微距毛发 + 慢镜头
- 关键点：暖色柔光，治愈氛围；Eye-Level 平视，动物居中，萌态动作，85mm 浅景深，背景温暖散景；微距特写毛发/爪垫/鼻头/眼睛，单根毛发透暖色逆光；慢镜头动态瞬间（甩头、跳跃、打哈欠），毛发飘动 + 惯性延迟
- 接法：动物角色同样要三视图锁定；不写拟人对白进画面，萌态靠动作

## 十五、Before/After 变身类

- 信号词：变身、改造、前后对比、换装
- 主推 liveaction，备选 pixar3d
- 核心参数：9:16，5–8 秒；Static → 遮挡/闪光转场 → Static
- 关键点：转场瞬间的视觉冲击 + 前后对比极致反差；前半段朴素/混乱/旧，低饱和冷色调；转场瞬间手遮镜头/闪光/Whip Pan/物体飞过，Speed Ramp 加速；后半段华丽/整洁/新，同角度 Static，高饱和暖色调，Slow Zoom Out 揭示全貌
- 接法：前后两段必须同机位同角度，否则对比不成立；写进镜头卡的机位字段，不只写在提示词里

## 十六、Meme/Loop/GIF 风格短片

- 信号词：循环、Loop、GIF、表情包动图、梗
- 主推 pixar3d，备选 cel2d
- 核心参数：1:1 或 9:16，2–4 秒（极短）；简单循环动作 + Static/缓慢 Orbit
- 关键点：**首尾帧无缝衔接**；动作必须“回到原点”（点头→回正、旋转→360° 整圈、弹跳→落回原位）；避免位移（角色不能在循环中产生净位移）；背景简洁（纯色/渐变/简单几何），减少背景断裂感
- 接法：本仓库的无缝循环验收（首尾帧平均像素差）同样适用；2–4 秒不适用 N = D ÷ 10 的分段公式，整段一次生成

## 十七、视频编辑/剧情颠覆

- 信号词：改编、颠覆、换角、换风格、重剪
- 主推：按新风格走建议表（本场景只定编辑结构）
- 核心方法：保留 / 修改 / 新增三分法——明确列出保留的元素（运镜/动作/场景）；具体修改点，精确到时间段；新走向的镜头
- 关键点：三种模式——元素替换（换角色/场景/服装）、剧情颠覆（反转走向）、风格改写（保留运镜和动作，只改风格）；保持镜头连贯，只在指定位置修改
- 接法：对应本仓库的“重拍错段”规则——只重做错的那一段，不动整片；改编类先过文字稿关卡 1，不直接改视频

## 十八、视频延长

- 信号词：延长、续拍、接下去、继续
- 主推：与原视频同风格（本场景只定延长结构）
- 核心参数：源视频 ≤30 秒，新增 4–30 秒，最终 ≤60 秒；提示词只控制新增部分
- 关键点：从源视频尾帧的动作动量接续，不写“重新开始”；交接状态（位置、朝向、道具、光线）写清
- 接法：对应本仓库的尾帧锁定（上一段尾帧当参考图）+ “尾帧即下镜首帧”规则；超过 60 秒按多段分镜走，不靠延长硬撑

## 十九、剧情补全与分镜图转视频

- 信号词：分镜图、漫画、故事板转视频、补全
- 主推：按题材走建议表（本场景只定输入方式）
- 核心方法：先明确格子顺序、人物映射和各格时间范围；分镜图转视频——引擎读分格顺序，按声明的阅读顺序补全镜头之间的动作与过渡；漫画分格动态演绎——每格一个动作，不跨格跳切；图片情绪发散——一张图定情绪，视频按情绪展开
- 接法：对应本仓库的关卡 2（故事板）→ 关卡 3（试点）；故事板图版就是这里的输入图，顺序写进镜头卡

## 二十、多帧故事/多宫格分镜

- 信号词：多帧、宫格、关键帧、组图
- 主推：按题材走建议表（本场景只定输入方式）
- 核心方法：上传关键帧图片或多宫格分镜图，引擎按声明的阅读顺序补全过渡；图片顺序按叙事顺序传（第 1 张 = 开头，最后 1 张 = 结尾）；提示词描述整体故事和风格，不需要逐帧描述；保持角色外貌在所有画面间完全一致
- 关键点：多张关键帧/角色设计图需要连贯故事时用多帧故事；30–180 秒连续剧情需要精确分镜控制时用超长视频 + 时间轴；需要精确时间轴控制（卡点/节奏）时用时间戳分镜
- 接法：对应本仓库的三视图 + 故事板（关卡 2）；关键帧图就是三视图和场景画布的来源

## 二十一、时间静止/子弹时间

- 信号词：子弹时间、时间静止、凝固、定格穿越
- 主推 liveaction，备选 pixar3d
- 核心参数：提示词必须含“场景完全静止”；运镜快速推轨或三维穿梭；提供首帧图效果大幅提升
- 关键点：静止场景中的元素（漂浮的碎片/水滴/火星/人群）写清；镜头极速穿梭/环绕经过静止元素，最终定格于画面核心焦点
- 接法：首帧图 = 本仓库的镜头卡首帧字段；静止元素清单写进镜头卡，不写“时间停止了”这种空话

## 二十二、多镜头混剪序列

- 信号词：混剪、蒙太奇、预告片、快闪
- 主推：按题材走建议表（本场景只定剪辑结构）
- 核心方法：提示词含“多镜头视频”；第一镜/第二镜/第三镜各写画面 + 运镜；节奏极快，镜头切换凌厉
- 关键点：牺牲空间连续性，换密集叙事节奏——只适用于预告片、MV、快闪，不适用于连续剧情
- 接法：本仓库的连续剧情不用混剪（连续性审计会拦）；混剪只用于预告片类单集，且要在文字稿里明示“本集为混剪，不走连续性审计”

## 二十三、极限第一人称视角

- 信号词：第一人称、POV、FPV、无人机、飞剑
- 主推 liveaction，备选 pixar3d
- 核心方法：真实人类 POV——带视线转移（看左、看右、低头、抬头）；飞行物体 FPV——无人机/飞箭/飞剑的高速穿越；生物第一视角——飞鸟/走兽的低空掠过
- 关键点：视线转移要写清顺序（先看哪、再看哪）；速度感靠近处物体拖影，不靠镜头乱晃；落地/撞击前留 1 秒减速，否则晕
- 接法：POV 段的机位字段写“第一人称”，不写具体机位名；三视图不适用 POV 段（看不见主角），改为写“所见之物”清单
