# 场景一致性规范（v1.7 新增，硬规则，通用）

## 原则

人物会漂，场景也会漂，而且场景漂了更难发现：上一集沙滩是白天，
下一集沙滩突然变傍晚，灯塔位置换了边，潮池里多了没见过的东西。
本规范与 `docs/CHARACTER_CONSISTENCY.md` 并列：**人物三视图锁死，场景画布锁死，
两者都按季锁死，不按集重新发明。**

## 季层：场景一次锁死，整季复用

| 项目 | 写法（占位符，换 IP / 换季时只填这里） |
|---|---|
| 世界地图 | 一张文字地图，地点、路线、距离感，见 `docs/WORLD_TIMELINE.md` |
| 场景清单 | 每季 ≤6 个主场景，写死在季 bible 里，集里不加新主场景 |
| 场景画布 | 每个主场景一张：全景 + 固定元素清单 + 主色调 + 光线 + 默认机位 |
| 固定元素 | 每场景 [固定元素 1]、[固定元素 2]、[固定元素 3]，缺一不可，多一件要批 |
| 时间 | 每场景默认时间 [白天/傍晚]，换时间必须有剧本动作（例如“天黑了”） |
| 禁项 | [本场景不能出现的元素、颜色、天气] |

检查（任一项不过，场景不通过，不进故事板）：
- [ ] 场景画布与文字稿一致，固定元素、主色调、光线、机位都对得上
- [ ] 同一场景在不同集里，固定元素、主色调、光线、机位方向不无故变
- [ ] 场景切换沿地图上的路线走：只能去相邻地点，不能瞬移；故事顺序可以变，地图不变

## 集层：每集最多加 1 个新场景

- 每集只能用季 bible 里的场景，新增场景每集 ≤1 个，且必须在本集文字稿里写清
  它从哪来、长什么样、以后还用不用。
- 新增场景用完即走的，写明“本集客串场景，不进季 bible”；以后要复用的，补进季 bible，
  并补一张场景画布。
- 客串场景不能改变主场景的固定元素和路线。

## 每段验收：对照场景画布核对（成片帧为准）

每段抽 2 秒帧和 5 秒帧，对照场景画布逐项核对：

| 核对项 | 通过标准 | 不通过例子 |
|---|---|---|
| 固定元素 | 清单里的元素都在，位置一致 | 灯塔换了边、潮池没了、多了没见过的建筑 |
| 主色调 | 与场景画布一致 | 沙滩变灰、夜景变白天 |
| 光线/时间 | 与默认时间一致，或有换时间的剧本动作 | 白天无故变夜晚、晴天无故变雨天 |
| 机位方向 | 与默认机位一致，或有转场动作解释 | 同一场景机位左右翻 |
| 背景角色 | 不无故出现/消失 | 上一镜没有的角色，下一镜突然站在人群里 |

任一项不通过，该段不通过，重生成；连续两次漂，改拍法（只拍固定机位、大景别，
减少模型发挥空间），仍不通过，降级为静态场景画布 + 旁白，不继续烧积分重生成。

## 与人物一致性的关系

- 人物审计（`scripts/character_check.py`）管人，场景审计（本规范 + `scripts/check_season.py`）
  管地，两张表都要通过才进交付。
- 人物和场景都按季锁死：季内换人物、换场景、换主色，都要先改季 bible，用户点头后才生效，
  不能在某一集里偷偷换。
