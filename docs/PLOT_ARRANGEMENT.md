# 情节编排说明

## 三幕节拍（60 秒版，文字故事约 60–90 秒）
- 第 1 幕（约 30%）：立主角、立目标、埋伏笔。观众在第 1 幕结束时能说出“谁、要干什么”。
- 第 2 幕（约 40%）：出问题、试一次失败、升级一次。只升级一次，不能每幕换一个新问题。
- 第 3 幕（约 30%）：第二次能力更夸张、反转 payoff、具体画面收尾（不是“大家都很高兴”）。

## 因果链图（每集必画，文字版即可）
```
上一幕结果 → 这一幕起因 → 这一幕行动 → 这一幕结果 → 下一幕起因
```
断一环，即不通过。人物出现必须有原因：本来就在那个地点，或上一幕叫他来的。

## 升级一次原则
麻烦只能升级一次。第一次失败是“方法不对”，第二次成功是“方法对了 + 能力更大”，不是“问题变大了”。

## 伏笔-payoff 对照表（每集必填）
| 伏笔（第几幕） | 内容 | payoff（结尾） |
|---|---|---|
| 第 1 幕 | 画上没有名字 | 结尾：礼物是给大家的，不用写名字 |

没有对照表，反转即不通过。
