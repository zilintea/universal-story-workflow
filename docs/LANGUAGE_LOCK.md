# 语言锁定（v2.8）

## 问题

中文典故的对话、旁白、字幕里出现了英文。根因有三处，都是技能里的英文默认值漏进来的：

1. `templates/story_text_output.md` 审计表里还留着一句“目标语言是否为英语”（英语启蒙时代的残留），等于告诉审计员“英语才是对的”。
2. `scripts/check_story.py` 默认语言是 `"en"`，没写语言时按英语档案走。
3. 没有一道检查真的去验“对话/旁白/字幕是不是目标语言”——只查了 language 字段非空，字段写 zh、内容写英文也能通过。

## 规则

**目标语言 = 用户那句话的语言。** 用户用中文说，目标语言就是中文；用户用英语说，就是英语；用户说韩语就韩语。不猜、不默认英语。

**默认值（v3.0）：人物类剧集用户没特别指定时，目标语言一律中文。** 只在两种情况改：用户明确指定其他语言（如“用英语讲”），或明确指定非中国背景（如“美国故事”）。人物形象同理，一律东方人物（见 `docs/CHARACTER_DEFAULTS.md`）。非人物类内容（风光、美食、汽车等）不受这条管，按题材走。

## 多语言对话（v3.2）

**问题：** 不同国家的人同框，对话该用什么语言？比如一个中国人和一个美国人对话，
一个说中文、一个说英语——按 v2.8 的单语言锁，这集没法写。

**评估：** 语言锁的本意是观众听得懂、前后一致，不是强制所有人说同一种话。
旁白和字幕是讲给观众听的，必须用目标语言；对话是人物自己说的话，
各人说各人的语言才真实。报告语言和内容语言分开的原则不变。

**规则：**

1. **旁白始终用目标语言。** 旁白是讲给观众的，不跟人物走。
2. **对话按说话人走。** 每个人物默认说目标语言；故事明确指定某人物说别的语言时，
   该人物说指定的语言。故事 JSON 的 `character_languages` 字段写映射
   （如 `{"C2": "en"}` 表示 C2 说英语）；对话条目可写 `{"speaker": "C2", "text": "..."}`
   或直接带 `"lang"` 显式指定本句语言。
3. **字幕用目标语言。** 非目标语言的对话行，字幕写翻译（原文留在对话轨备注里）。
4. **每句都查。** `scripts/check_story.py` 按每句的有效语言查一致性：
   显式 lang > `character_languages[说话人]` > 目标语言；`character_languages` 的值
   须有语言档案（`data/languages/<code>.yaml`），没有即不通过。
5. **音频按句走。** 配音时每句按自己的语言合成（技能只给文字 + 时间戳，合成是用户自己的）。

**报告语言和内容语言分开。** 报告、说明、审计结论用什么语言写，可以配；但内容语言（标题、故事、对话、旁白、字幕）必须跟目标语言一致，两者互不干扰。（借鉴 shuohao-skills：报告语言可配，内容语言跟原著走。）

## 画面内文字的语言（v3.3）

**问题：** 《孔子的一生》第 1 段，提示词用英文写画面描述 + “Qufu city”，
模型在城门牌匾上写了英文 “Qufu City Gate”。故事明明是中国，牌匾却是英文。

**规则：画面内文字的语言 = 目标语言。** 牌匾、招牌、旗帜、碑刻等画面内文字，
用什么语言，跟故事走，不跟提示词的语言走：
中国场景一律汉字，不许出现英文字母；其他国家跟其语言（英文故事用英文，韩文故事用韩文）。
旧规则“画面内文字 = 无”是错的——中国城门肯定有汉字，问题不是有没有字，是字用的哪国语言。

**提示词约束：**

1. 视频提示词里不写罗马拼音地名、人名（“Qufu”会被模型直接抄上牌匾）。地名只进旁白和字幕（后期）。
2. 提示词末尾写清画面内文字的语言，如 “all visible writing is in Chinese characters, no English letters”。
3. 验帧时核对：0.5 秒 / 5 秒 / 9.9 秒三帧，画面内文字的语言 = 目标语言；出现其他语言文字即不通过，重生成。

**视频提示词例外，但只限画面描述。** 视频提示词用英文写画面描述（生成模型的工作语言），但其中的对话、旁白、字幕文本必须用目标语言写，不翻译、不转写。

## 怎么用

1. 文字稿模板里有一节“语言锁定”：目标语言（按用户那句话定）+ 报告语言，写死在锁表里。
2. 审计：`scripts/check_story.py` 查语言一致性——
   - zh：对话、旁白里不得出现拉丁字母单词（数字和标点除外）；
   - en：对话、旁白里不得出现 CJK 字符；
   - ko：对话、旁白里须含韩文，不得出现 CJK 汉字（汉字词除外——本规则只查纯汉字串，暂不拦）；
   - ja：对话、旁白里须含假名。
   不合即不通过，改文字稿，不进视频。
3. `checklists/language_audit.md` 顶部加通用核对项（不只教学模式查）。
4. 旁白时长：`scripts/check_narration.py` 按语速预估旁白时长（zh 约 280 字/分钟，en 约 150 词/分钟），与 D 相差超过 20% 时出“注意”（不拦关卡，但要写进文字稿的审计表，决定是加长旁白还是接受留白）。

## 不改的

- 教学模式（`docs/TEACHING_MODE.md`）仍是英语启蒙专用的可选模式，不动；语言锁定是通用规则，教学模式也要过。
- 语言档案（`data/languages/`）不动，只读。
