# 无限主画布（v3.11）

## 一句话

**全集共用一张总图当唯一视觉真源。** 人物、物品、场景、色卡拼在一张画布上，
每段视频生成时第一张参考图永远是它，第二张才是尾帧或三视图。

## 为什么叫“无限画布”

- 一张画布管全集：不是每段各传一张散图，而是所有锁定内容长在同一张画布上，
  模型每次看到的是同一套人、同一套物、同一个场景，漂移无处藏身；
- 只加格，不重画：新物品、新场景出现时，只往画布上加一格，
  已锁死的格一字不改、一笔不动；
- 改版即升版：某件物品改了（例如碗改盏），整张主画布升版（M1→M2），
  旧版作废，后续各段只用新版，改版原因记进文字稿。

## 画布结构（建议布局，不写死尺寸）

- 顶栏：全片人数（例如“全片共 3 人”）、画幅、风格、目标语言；
- 第一行：人物 C1、C2……（三视图缩略 + DNA 一行）；
- 第二行：关键物品 I1、I2……（物品画布缩略 + DNA 一行 + 非此物清单一行）；
- 第三行：场景 S1、S2……（场景画布缩略）；
- 底栏：色卡（主色、次色、标志物色，各写色值）。

每格编号与锁定表一致（C1、I1、S1……），只写编号引用，不重复写全文。

## 使用规则

1. 关卡 2 通过后才有主画布；主画布未通过，不进视频。
2. 每段视频生成：第一张参考图 = 主画布当前版；第二张 = 上一段尾帧（连续镜）
   或三视图（切换镜）；物品特写：第三张 = 主画布上该物品格的裁剪图。
   **变形主体例外（v3.13，见 `docs/GROWTH_SEQUENCE.md`）：生长主体出场时
   第一张参考图只传当前阶段格裁剪（或该阶段物品画布），不传整张主画布；
   主画布仍作全集存档与验收总表，各阶段格全拼在上面。**
3. 提示词里写“以主画布 M× 为准”，再逐字复用出场人物 DNA 与物品 DNA，
   并写死人数与物品数量（“画面里一直只有 3 人”“只有 3 只盏”）。
4. 验帧时对照主画布逐格核对：人物、物品、场景、色卡，任一项漂移即不通过，
   只重做该段。
5. 文件路径写进故事 JSON 的 `master_canvas` 字段，`scripts/check_story.py` 查文件存在。

## 与旧流程的兼容

v3.11 之前的旧稿没有 `item_sheet` / `master_canvas` 字段，脚本跳过检查，
不追溯；新活必须有。旧稿要续做新段时，先补物品画布与主画布再开工。
