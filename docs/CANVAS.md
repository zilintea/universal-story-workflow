# 画布系统

## 五套画布，分工不同（v3.11：三套变五套）

### 0. 无限主画布（每集一张，唯一视觉真源）
- 内容：三视图 + 物品画布 + 场景画布 + 色卡拼成的一张总图，分格编号，顶栏写全片人数与画幅；见 `docs/MASTER_CANVAS.md`。
- 使用：每段视频生成时第一张参考图永远是主画布；改版即升版，旧版作废。
- 检查：主画布未通过，不进视频。

### 4. 物品画布（每件关键物品一张，v3.11 硬门）
- 内容：正面 / 侧面 / 手中比例 + 材质 + 色值 + 状态 + 物品 DNA + 非此物清单；见 `docs/ITEM_CANVAS.md`。
- 入选：出现 ≥2 段，或被人持有/使用，或是剧情关键物，或用户点名。
- 检查：形状、尺寸与手的比例、材质、数量、状态任一项不符即不通过；`item_sheet` 字段必填且文件存在。
- 变形主体（v3.13）：生长序列 P1，下挂多阶段图版 P1-S1、P1-S2……，每阶段一张物品画布，验收只对照本阶段；见 `docs/GROWTH_SEQUENCE.md`。

### 1. 角色画布（第 1 步锁死，每位出场人物一张，锁定后复用）

### 1. 角色画布（第 1 步锁死，每位出场人物一张，锁定后复用）
- 尺寸：1920×1280，一张
- 内容：三视图（正面 / 侧面 / 背面）+ 表情行（笑、委屈、得意、困、惊讶，至少 5 个）+ 颜色卡（主色、次色、标志物色，各写色值）+ 体型比标尺
- 边栏文字（不进生成图，只作检查清单）：体型比、主色、标志物、能力、禁项、角色 DNA（一句话，之后逐字复用）
- 检查：三视图前后一致、无多手多脚、无文字、无已知 IP 造型；三视图未通过不进故事板。见 `docs/CHARACTER_CONSISTENCY.md`。

### 2. 故事板画布（每集用一次，v3.12 改无限画布交付）
- 交付物：一个可平移缩放的无限画布（见 `docs/INFINITE_CANVAS.md`），不是一张 9 宫格平面图；9 宫格图（1920×1280、3 列、每张最多 9 格）只作总览缩略图，可附在画布顶部
- 风格：黑白素描，线条干净，不上色（上色留给视频阶段）
- 每格一节点：一个动作、一个地点、物品状态（完好/破损必须画出来），节点带稳定编号与链接（例如 `#seg2-shot3`）、本镜抽帧图、视频文件链接、状态与偏差说明、“重制此镜”入口
- 检查：格数、序号、动作与剧本一一对应、反转格有伏笔呼应；每个节点都能被链接直达、都能单独指定重制

### 3. 场景画布（每主场景用一次，锁定后复用）
- 尺寸：1920×1280，每场景一张
- 内容：场景全景 + 固定元素清单（例如[场景 A]：[固定元素 1]、[固定元素 2]、[固定元素 3]）
- 边栏文字：色调、光线、默认机位、禁项（例如：不换色调、不加新固定元素）

## 生成方式
五套画布均用纯文字提示词生成，不上传设定图（上传曾因上游 400 失败，纯文字更稳）。
主画布由已通过的各张画布拼成，不重新生成人物、物品、场景，只做拼版与编号。
`scripts/make_canvas.py out.png --panels G` 可生成空白 G 格画布模板（白底、黑框、序号），用于检查布局、格数、留白，不代替 AI 生成的故事板。
