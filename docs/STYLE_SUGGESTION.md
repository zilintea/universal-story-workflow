# 风格建议（v2.9）

## 规则

用户给一句话提示后，**先给风格建议，再出文字稿**。建议写进文字稿的“风格”栏，随文字稿一起过关卡 1。

- 建议 = 主推 1 个 + 备选 1 个 + 一句话理由。
- 用户没别的提示 → 用主推。
- 用户点名 → 用点名的，备选作废。
- 用户说“换一个” → 用备选，再给一个新备选。

## 场景模板

题材再往下细，见 `docs/SCENARIO_TEMPLATES.md`：23 个场景（电商、仙侠、短剧、美食、MV、一镜到底、微距、汽车、风光、长视频、游戏 PV、恐怖、旅行、宠物、变身、循环、改编、延长、补全、多帧、子弹时间、混剪、第一人称），每个场景有信号词、主推风格、核心参数、关键点和接法。`scripts/suggest_style.py` 命中场景时会在建议里带上场景名。

## 脚本

`scripts/suggest_style.py "一句话提示"`：按上表匹配信号词，输出主推、备选、理由、命中的场景（JSON）。无信号时输出默认组合。脚本只建议，不锁定；锁定发生在文字稿关卡 1。

## 借鉴

- seedance-shot-design 的场景模板（题材 → 模板）：建议表就是它的精简版，23 个场景已按本仓库语言改写入 `docs/SCENARIO_TEMPLATES.md`。
- universal-video-skills 的 style lenses（题材 → 导演词汇）：主推/备选的“理由”一栏就是它的用法，风格不是口味，是题材决定的导演选择。
