# 音频交付规范（v1.3 新增）

## 音频单独生成、单独成文件
- 旁白、对话、音乐分轨，三个文件分开交，不混成一轨就交。
- 旁白文件：narration_en.mp3，英文旁白全稿，语速 90（启蒙慢读）。
- 对话文件：dialogue_en.mp3，英文对话按出场顺序排列，每句之间留出跟读停顿。
- 音乐文件（如有）：music.mp3，单独交，不盖过对话和旁白。
- 音频文件不依赖视频文件存在：用户可以只听音频跟读，也可以只看视频。

## 发音检查
- 关键词汇处慢读、重复、停顿，见 docs/WORD_HIGHLIGHTING.md。
- 音频生成后要查时长和文件大小，空文件、截断文件不能交付。
