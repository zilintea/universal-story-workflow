# 文化锚点（v2.7）

## 规则

**文化是项目属性，不是风格属性。** 风格（`data/styles/` 里的卡）只管造型、质感、光线、运镜，跨 IP 通用；文化锚点属于本集 IP / 本集世界，写在文字稿锁表里。风格卡的 prompt 里不加全局文化词——写进去以后拍西方故事也会带中国味，反过来也一样。

## 为什么“中国元素”四个字不够

- 模型没有文化默认值：风格描述里只有造型词时，它顺着训练数据的多数往好莱坞那套走（美国红岩峡谷、西式面包、西式僧袍）。
- “中国元素”是空词：模型会自己脑补成龙袍、灯笼、熊猫，符号化、更错。
- 教训来源：2026-11-05《三打白骨精》试点 v2，地貌是美国红岩峡谷、饭篮里是西式面包、唐僧和村姑造型偏西式/韩式。

## 写法：五类，各写一行具体物

有文化属性的 IP 必填，通用故事可空。每一类只写**具体物**，不写空词：

| 类 | 西游例子 | 西方例子 |
|---|---|---|
| 服饰 | 汉服、僧袍、虎皮裙 | 哥特长袍、皮甲、斗篷 |
| 食物 | 馒头、包子 | 面包、烤鸡 |
| 器物 | 竹杖、木篮、瓦罐 | 铁剑、木盾、石杯 |
| 地貌 | 黄土高原、枯松、石板路 | 石板城堡路、针叶林、石桥 |
| 色彩 | 朱红、明黄 | 冷灰、深蓝 |

## 怎么用

1. 文字稿模板里有一节“文化锚点”，五类各写一行，写死在锁表里（见 `templates/story_text_output.md`）。
2. 每段视频提示词逐字复用文化锚点（脚本 `scripts/apply_culture.py` 自动拼，见下）。
3. 审计：`scripts/check_story.py` 查 culture 字段——五类齐全、每类非空、不含空词（“中国元素”“西方元素”“中国风”“东方元素”单独出现即不通过）；`checklists/continuity_audit.md` 核对每段提示词里确实带了锚点。
4. 西方题材同理：在同一位置换西方锚点，不用另改技能。

## 脚本

- `scripts/apply_culture.py story.json segments.json`：读故事 JSON 的 `culture` 字段（五类），读分段提示词 JSON（`[{id, prompt}]`），每段提示词后逐字拼上文化锚点，输出 `[{id, prompt}]`。故事 JSON 没有 `culture` 字段时原样输出，不报错。
- `scripts/check_story.py`：culture 字段存在时查五类齐全、非空、无空词；不存在时跳过，通用故事不受影响。
