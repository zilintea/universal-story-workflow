# 动画制作标准流程（用户未提及的部分，按此流程补齐）

## 前期（Pre-production，文字通过后才进）
1. 世界锁定：世界地图、空间规则、时间线（WORLD_TIMELINE.md）
2. 角色锁定：角色画布、人物锁定表（CONTINUITY.md）
3. 剧本锁定：文字故事 + 学习目标 + 警示点 + 三审计通过
4. 故事板：9 格（短视频）或按节拍格数（剧集/电影），逐格核对
5. 动态分镜（Animatic）：故事板 + 旁白/对话音频粗剪，卡时长、卡节奏，不通过不进制作

## 制作（Production）
1. 布局（Layout）：每镜机位、景别、轴线、背景，见 EDITING_STANDARDS.md
2. 动画：角色动作，动作匹配，表情，口型（对话镜口型对上关键词即可，不要求全句口型）
3. 背景：场景画布，固定元素、主色调、光线不变
4. 合成：角色 + 背景 + 光影，检查物品/场景连续

## 后期（Post-production）
1. 剪辑：按 edit_check.py 通过的分镜表剪，硬切为主，J-cut/L-cut 只用于声音
2. 声音：旁白、对话、音乐分轨，见 AUDIO_DELIVERY.md
3. 字幕：单独时间戳文件，见 SUBTITLES.md（v1.4 起不内嵌）
4. 质检（QC）：安全线 8 项、连续性、字幕时间戳、闪光频率、音量，逐项打勾

## 交付（Delivery）
- 分镜单独文件 + 字幕单独文件 + 音频单独文件 + 文字故事 + 审计表，见 VIDEO_DELIVERY.md
- 合并成片只在用户明确选择时做
