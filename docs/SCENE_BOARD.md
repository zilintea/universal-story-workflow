# 场景设定板（v3.21 新增，硬规则，通用）

## 解决的问题

做漫剧，大家都盯着人物，场景往往是最后才想起来的。结果就是：每个镜头换一个背景，人物站在哪儿都像“贴”上去的。第一个镜头里书店的窗在左边，第三个镜头变成了右边；上一幕的院子里有棵枣树，下一幕树没了。

根因：场景是每次生成时凭文字重发明的，没有一张定死的图。人物有三视图锁死，场景却没有对应的锁。

## 原则：场景是常量，人物是变量

**场景先出“无人版”。人物先别进来，先把这个地方本身定下来：它长什么样、有几个角度、一天里有哪几种光、里面的东西放在哪。**

为什么要出“无人版”，三条理由：

1. **人物是变量，场景是常量。** 你要换十个角色、拍二十个镜头，场景只能有一个。先把场景定下来，之后的每一张图，都是“人物去场景里演”。
2. **没有人，模型才会认真画空间。** 一旦画面里有人，模型的注意力会被人带走，背景就变成了模糊的一团。无人版里，每一块砖、每一盏灯，它都会画清楚。
3. **将来人物要“放进去”。** 有了无人版，之后出图时把场景图当参考图、再叠上人物卡，两个“锚点”一起用，背景就不会乱。

## 设定板版式（六格，一张图）

每个场景一张设定板，同一套版式：

| 位置 | 内容 | 作用 |
|---|---|---|
| 左 | 主场景大图，广角建立镜头 | 一眼看清这个地方 |
| 右上 | 多角度，三个小图 | 同一空间的不同方位 |
| 中 | 光线时段，同一空间的三种光 | 布局完全一致，只有光变 |
| 左下 | 空间结构，一张俯视平面示意 | 标出三个镜头机位（1、2、3） |
| 下 | 材质细节，四个特写，加一排色板 | 这个地方的质感来源 |

最要记住的是两块：**光线时段**和**空间结构**。前者保证“同一个地方”在早晨和傍晚都认得出来，后者让你写分镜的时候，知道机位可以放在哪。

## 五条规则

1. **一定是无人。** 提示词里明确写“不出现任何人物、人影、人脸”，否则模型会自作主张加人。
2. **同一个空间，至少出三种光。** 晨、午、昏，或者昼、夜、雨。光线变，空间不变，这样将来换时间拍摄，不会穿帮。
3. **把机位画出来。** 一张简单的俯视平面图，标出 1、2、3 机位，写分镜时你会省很多事。
4. **给每个场景一个“锚点物”。** 一棵孤树、一排宫灯、一台自动售货机，观众靠它认出“还是那个地方”。
5. **保留“使用痕迹”。** 磨损、晒物、锈迹、苔痕，这些让场景不像棚拍。

## 怎么用：人物“放进去”

场景图做好之后，人物“放进去”的办法：

- **场景图当参考图，人物卡当参考图，两个一起传。** 提示词里写明“人物站在这个场景里的哪个位置，朝向哪里，什么动作”，场景的结构、人物的长相，都由参考图决定。**主画布生成时用设定板主图（左上主场景大图）当图像参考，提示词写死位置：锚点物与所有物品的位置与参考图完全一致，不移动、不新增、不删除，只加人物（见 `docs/DRIFT_AUDIT.md` 位置锁定技法）。**
- 视频生成时，参考图顺序：第一张主画布，第二张场景设定板（本段场景），第三张上一段尾帧或三视图。场景设定板是本段场景的视觉真源，结构、固定元素、锚点物、光线都以它为准。
- **主画布出完做漂移审计（见 `docs/DRIFT_AUDIT.md`）：对照设定板主图逐项列移动/新增/缺失，锚点移动与大件缺失不通过，移动 + 新增 ≥ 3 项重出，审计表写进 log.md。**
- 分镜按空间结构图上的机位写：机位 1、2、3 是已标好的位置，不凭空发明新机位；换机位时写清从哪个机位到哪个机位，路线沿平面图走，不“穿墙”。

## 在流程里的位置

- **第 0 步世界空间线时定场景清单**：每个地点一张设定板，地点、路线、锚点物、固定元素先写进世界地图。
- **第 6 步出画布时出设定板**：场景画布升级为场景设定板（无人版），每个场景一张，不是一张单图。设定板通过（关卡 2）才进视频。
- **按季锁死**：设定板与场景画布同级，按季锁死，不按集重新发明；改版即升版，旧版作废。

## 检查（任一项不过，设定板不通过，不进视频）

- [ ] 无人：画面里没有任何人物、人影、人脸
- [ ] 主场景、三个角度、三种光、平面图、四材质、色板，六格齐全
- [ ] 三种光是同一空间、同一布局，只有光变，固定元素和锚点物位置不变
- [ ] 平面图标出 1、2、3 机位，机位与主场景、多角度对得上
- [ ] 锚点物在主场景、角度、光线三处都在，位置一致
- [ ] 材质特写与主场景对得上，有使用痕迹（磨损、晒物、锈迹、苔痕至少一处）
- [ ] 色板与主场景主色一致

## 与场景一致性的关系

本文件是 `docs/SCENE_CONSISTENCY.md` 的升级：场景画布从“一张单图”升级为“一张六格设定板”，其余规则不变——固定元素、主色调、光线、机位、背景角色五项验收，仍按场景一致性规范逐段核对。
