# 影视剪辑标准（v1.4，脚本自我评估后改写）

## 自我评估结论（先说旧脚本的问题）

旧脚本（conceive / check_story / highlight_words / make_canvas）只做了“故事逻辑”和“语言”检查，没有做“剪辑”检查：
- 没有 180 度轴线、没有 30 度规则、没有动作匹配、没有景别变化、没有转场类型、没有物品/场景连续性逐对核对
- 一个故事在文字上通过了，剪成视频时仍可能出现：人物朝向左右乱跳、物品瞬移、场景颜色突变、同一角度跳切
- 本版按影视剪辑标准补上这些检查，脚本从“故事检查”升级为“故事 + 剪辑检查”

## 剪辑标准（每集必查，见 checklists/continuity_audit.md 和 scripts/edit_check.py）

### 1. 180 度轴线
- 同一场景内，机位必须在轴线同一侧。两人对话时，A 在左、 B 在右，不能在下一镜左右互换。
- 轴线字段：每镜写 camera_side（left / right），同一场景内 camera_side 不变，场景切换时才可变。

### 2. 30 度规则
- 同一主体、同一场景连续两镜，机位角度变化必须 ≥30 度，或景别变化必须明显（例如全景 → 特写），否则就是跳切，不通过。
- 字段：每镜写 angle_change（相对上一镜的角度变化，度数）和 shot_scale（wide / medium / close）。

### 3. 动作匹配切（match on action）
- 动作进行中切镜，动作本身不能断、不能重复、不能倒退。例如：跑出门的动作，上一镜脚抬起，下一镜脚落下，不能上一镜已出门、下一镜又在门里。
- 字段：每镜写 action（本镜的核心动作）和 action_continues（是否承接上一镜动作）。

### 4. 视线匹配（eyeline match）
- 人物看向某物/某人，下一镜必须是他看的东西，不能是无关画面。看向左，下一镜的东西应在左。

### 5. 景别节奏
- 每镜 ≥2 秒；对话镜和反应镜交替；连续 3 镜同一景别即节奏单调，要改。
- 60 秒版建议：全景立场景 → 中景讲动作 → 特写讲情绪/物品，循环，不一直用同一景别。

### 6. 声音剪辑（J-cut / L-cut）
- 对话/旁白可以提前 0.5 秒进下一镜（J-cut），或延迟 0.5 秒留在上一镜（L-cut），但不能整句错位。
- 字幕时间轴按声音剪辑点排，不按画面切点硬排。

### 7. 转场
- 默认硬切；时间流逝用叠化；场景切换用前景遮挡划过或叠化；禁止无故跳切、禁止物品/场景瞬移（见 docs/CONTINUITY.md）。
