# 漂移审计（v3.25）

## 为什么要审

生成图不是 3D 渲染，没有固定不变的三维场景。模型每张图都从文字重新“想象”一遍，
概率性采样，物品位置、数量都会变。场景设定板（v3.21）只做到了“给参考图”，
没做到“验对应”：锚点和风格能稳住，但物品级的一一对应既没验也没锁，
模型就按自己的性子重排。漂移审计就是补这一道关：主画布、视频每段出完后，
对照上一级参考图逐项核对，动了、多了、少了的都列出来，决定过还是重出。

## 审什么（按级对照）

- **主画布 ← 设定板主图**：主画布出完后，对照设定板左上主场景大图。
- **视频每段 ← 主画布（首帧）与上一段尾帧**：每段三帧验帧时（v3.9），
  顺带对照主画布：锚点与大件物品的位置、数量有没有变。

对照清单（逐项打勾，写进审计表）：
- 锚点物：位置有没有动（上下左右）、大小有没有变。
- 大件物品（锁表里的每件）：位置、数量、有没有缺失、有没有新增。
- 背景元素（门窗、屏风、远山、家具）：位置、数量、有没有多出新的大件。
- 风格与光：风格有没有跑偏（这是风格问题，不是漂移，但同一张表里顺带记）。

## 审计表（写进 log.md）

| 物品 | 参考图位置 | 本图位置 | 结论 |
|---|---|---|---|
| 锚点：挂轴 | 床の间正中 | 床の间正中 | 一致 |
| 矮桌 | 画面右中 | 画面正中偏下 | 移动 |
| 左侧置物架 | 无 | 画面左侧新增 | 新增 |
| 炉 | 左前 | 桌后 | 移动 |
| 插花 | 床の间左 | 床の间左 | 一致 |

结论只许四种：一**致**、**移动**、**新增**、**缺失**。不要写“差不多”“有点像”。

## 通过标准

- **锚点物移动 = 不通过**，必须重出。锚点是场景的钉子，钉子动了整场就散了。
- **大件物品缺失 = 不通过**，必须重出（锁表里的物品不许丢）。
- **移动 + 新增 ≤ 2 项 = 通过**，但要在 log.md 里逐项披露（写清哪件动了、哪件多了）。
- **移动 + 新增 ≥ 3 项 = 不通过**，重出。
- 小件（茶筅、布巾、杯子）位置微调不计，只看大件与锚点。

## 位置锁定技法（重出时用）

漂移不是靠“多写几遍提示词”锁住的，靠的是**图像参考 + 写死位置**：

1. **主画布用设定板主图当图像参考**：生成主画布时，把设定板左上主场景大图作为
   图像参考传入（不是只靠文字描述），提示词里写死：
   “Keep the [锚点物] and all objects in exactly the same positions as the reference image.
   Do not move, add, or remove any object. Only add the characters [C1, C2] at [位置].”
   （中文提示词同理：锚点物与所有物品的位置与参考图完全一致，不移动、不新增、不删除，
   只加人物 [C1, C2] 在 [位置]。）
2. **视频用主画布当第一张参考图**（v3.21 已定）：视频提示词同样写死
   “所有物品位置与参考图一致”，不只写场景描述。
3. **重出上限 2 次**：同一张图最多重出 2 次。第 2 次仍不通过时，取漂移最少的一版，
   在 log.md 里逐项披露漂移，不许把漂移版当无漂移版交付。

## 流程位置

- 关卡 2 之后、关卡 3 之前：主画布出完先做漂移审计，通过才进试点。
- 关卡 3 试点与批量：每段三帧验帧时顺带做漂移审计，写进该段验帧记录。
- 审计表是 log.md 的一部分，不单独成文件。
