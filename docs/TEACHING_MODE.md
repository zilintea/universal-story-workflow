# 语言教学 / 少儿模式（可选模式，不在主流程里）

> v2.1 修正：本技能是所有场景通用的版本，主流程不预设语言教学、少儿、生活场景。
> 本文件是可选模式的说明，只在用户明确说语言教学 / 英语启蒙 / 给小朋友看时才用；
> 通用模式时不读本文件，不按本文件审计。

## 开启方式

用户一句话即可，如：“这集作语言教学用”“给小朋友看”“英语启蒙”。
开启后，本集及之后同系列默认保持该模式，直到用户说关掉。

## 本模式才有的要求

- 每集 ≤5 个目标语言单词 + ≤2 个目标语言句型 + 1 句主题 + 1 个生活警示点。
- 单词在目标语言对话/旁白里 ≥3 次，且至少 1 次在笑点里；句型重复 ≥2 次。
- 词汇按记忆规律复习：新词在 +1/+3/+7 集复习，每集新词 ≤5、复习旧词 ≥2。
- 旁白轨仍按 `docs/NARRATION_CONTINUITY.md` 写连续自然语言；
  词汇重复靠跟读和复习，不靠把旁白拆碎。
- 安全说明见 `docs/SAFETY_OPTIONAL.md`：安全只是说明文件，可查阅，不参与审计。

## 生活场景主题库（本模式时用）

每集主题必须来自生活场景，且必须同时写清警示点和教学点，否则不通过：

| 生活场景 | 警示点 | 教学点（英文） |
|---|---|---|
| 火灾 | 着火了先离开，不回头拿东西 | fire, smoke, run, shout, safe |
| 过马路 | 看红绿灯，绿灯才能走 | stop, go, look, road, safe |
| 陌生人 | 不跟陌生人走，不吃陌生人的东西 | no, stranger, help, mom, dad |
| 洗手 | 饭前便后洗手 | wash, hands, soap, water, clean |
| 触电 | 不碰插座和电线 | no, touch, danger, help |
| 玩水 | 不一个人去河边玩水 | water, danger, help, safe |
| 做菜 / 做手工 | 按步骤做，不跳步；危险步骤大人做 | wash, cut, cook, help, safe |
| 跌倒 / 生病 | 跌倒了告诉大人 | hurt, help, doctor, mom |

新主题不在库里时，先按“生活场景 + 警示点 + 教学点”三项补齐，再进故事，缺一项不进。
