# 模型易错对照表（v3.7 新增）

> 来源：Eian 手册的易错表，按本仓库语言重写；每条只写“错的样子 → 本仓库的写法”。
> 写提示词和审提示词时逐条对。更多细节见 templates/video_prompt_7seg.md。

| 模型容易犯的错 | 本仓库的写法 |
|---|---|
| 一群人同时做同一个动作 | 写清谁先谁后（“老爸第一个……过一两秒老奶奶才……小女孩最后……”）；首帧也不摆同一个姿势 |
| 本来该风做的事，人自己动手做了 | 先写原因，再写“两只手从头到尾都没有碰它” |
| 云、月亮、植物长出眼睛嘴巴 | 不写“卡通云”这种词；写纹理和样子（“蓬松的灰白色积云，只有棉絮一样的纹理和阴影”），动作只写它怎么移动 |
| 人往反方向走 | 方向按画面写（“朝画面左边走，跨过左边的店门”），不按故事写 |
| 一句话有两种意思 | 写具体到位置（“左上角石头房子的窗口里”），再加一句排除（“驾驶座一直空着”） |
| 东西的数量变了 | 数量直接写死（“只有一封黄信封，之后他怀里全是白信封”） |
| 写“不要怎么样”没用 | 尽量改成正面说法（“画面里一直只有首帧这几个人”）；改不成的，干脆不让那东西进有动作的镜头 |
| 模型自己联想道具的用法（壶总要出水） | 不让这个道具出现在有动作的镜头里 |
| 东西凭空出现 | 只用首帧里已经有的东西；动作要用的东西首帧里必须有 |
| 东西突然飞走或瞬间移动 | 写清它怎么动的（“顺着后脑勺往后一滑，接住，扣回头上”），不写结果 |
| 雨、帽子、纹身拍着拍着没了 | 首帧和尾帧都画上 |
| 闪电画得太写实 | 写“云里闪一下白光”，再把开头剪掉 |
| 一个镜头动作太多就乱了 | 每个镜头只写一两个主要动作，多了拆镜 |
| 动作的时间和写的不一样 | 写的时间只能算大概，多留一点时间，后期剪辑和变速对节拍 |
| 镜头推得没有写的那么明显 | 后期用代码再推一点 |
| 人的嘴自己在动 | 写明“人物不说话”，还动就用代码修 |
| 写了“没有音乐”还是混进音乐 | 片段自带的声音不用，后期另外加 |
| 结尾几帧突然跳到尾帧的样子 | 后期选一张没问题的画面，后面都停在这一张 |
| 第一张画面特别锐 | 直接把这一张去掉 |
| 视频越到后面越暗越冷 | 每条视频都按它自己的首帧把颜色调回来 |

## 审提示词时顺带查的三件事
- 两张图里的同一东西大小差了多少（比如杯子差 13%）：叠在一起看，差了就改图。
- 帽檐、左右有没有写反：放大看，再和设定图对一遍。
- 首帧和尾帧叠在一起有没有错位：不该变的地方（墙的颜色、杯子大小）两张图必须一样，
  不然视频里会慢慢变色、慢慢变大。
