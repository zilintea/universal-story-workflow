# 词汇复习与剧情推进（v1.7 新增，硬规则，通用）

## 原则

长篇剧集不是一集一集的随机主题合集，是按剧情推进的连续体。
两条线必须同时推进，缺一条就不通过：
- **剧情线**：主角每集学会一点，季终学会一件大事，季终的 payoff 必须在季首埋伏笔。
- **词汇线**：新词按记忆规律复习，学了不复习等于没学。

## 剧情推进（季弧 + 集弧）

- 季弧一句话：本季主角从 [起点状态] 到 [终点状态]，写死在季 bible 里。
- 集弧一句话：本集主角学会 [一件事]，是季弧的一步，不能与季弧无关。
- 角色成长不倒退：上一集学会的技能，下一集可以用；上一集丢失的物品，
  下一集不能无故出现；上一集害怕的东西，下一集不能无故不怕了——
  除非剧本明确写了“学会/克服/丢失”这个动作。
- 季终 payoff：季终那集要收的伏笔，必须在第 1 集埋下，第 1 集没埋，季终不能凭空收。

## 词汇复习：按记忆规律（间隔重复）

新词引入后，必须按以下间隔复习，间隔以集数为单位：

| 引入 | 第 1 次复习 | 第 2 次复习 | 第 3 次复习 |
|---|---|---|---|
| 第 N 集 | 第 N+1 集 | 第 N+3 集 | 第 N+7 集 |

规则：
- 每集新词 ≤5 个，复习旧词 ≥2 个（复习词不占新词名额）。
- 新词第一次出现必须在笑点或关键动作里，不能只在词汇表里出现。
- 复习不是念一遍：复习时旧词必须用在新的句子、新的动作里，不能复制上一集的原句。
- 季末（最后一集）必须复习本季全部核心词至少 1 次，方式是剧情复现，不是词汇表朗读。
- 复习表写在季 bible 里，每集文字稿开头列出“本集新词 / 本集复习词 / 下次复习在第几集”，
  缺一项不进故事板。

示例（占位符，不写死具体词）：
```
第 1 集：新词 [词 A][词 B][词 C]，复习 —，下次复习：第 2 集
第 2 集：新词 [词 D][词 E]，复习 [词 A][词 B]，下次复习：第 4 集（词 A、词 B）、第 3 集（词 D、词 E）
第 4 集：新词 [词 F]，复习 [词 A][词 B][词 D]，下次复习：第 8 集（词 A、词 B）
```

## 检查

`scripts/check_season.py` 按季 bible 的集表检查：
- 主题不重复（集主题、反转、结尾三项都不能与前面任何一集相同）
- 每集新词 ≤5 个，复习旧词 ≥2 个
- 每个新词在引入后的第 +1、+3、+7 集里至少复习 1 次（季末集数不够时，至少复习到季末）
- 季终 payoff 的伏笔在第 1 集出现过
- 角色、场景只用季 bible 里的，客串角色每集 ≤1 个，新增场景每集 ≤1 个
任一项不过，改季表或改本集，不生成视频。
