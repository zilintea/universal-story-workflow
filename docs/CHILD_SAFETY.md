# 少儿安全线（硬规则，一票否决）

见 EVALUATION_CHILDREN_FILM.md 第 2 节，8 条安全线全文：

1. 无暴力、无血腥、无恐怖、无跳吓、无死亡、无黑暗结局
2. 无危险模仿：火、电、水、马路、陌生人、高处，角色必须做正确安全行为且求助大人/伙伴，不能独自逞英雄
3. 无欺凌美化、无歧视、无嘲笑外貌/口音/家庭
4. 情绪安全：紧张情节当集解决，不留恐怖悬念过夜；失败后有安慰和修复
5. 语言安全：启蒙级词汇，无脏话、无成人梗
6. 视觉安全：闪光 <3Hz，无频闪、无快速红白交替
7. 声音安全：无突然巨响、尖叫、恐怖音效，音量平稳
8. 商业安全：不植入广告、不诱导消费

检查方法：每集文字稿完成后，先跑安全线 8 项，再跑逻辑/语言/剪辑审计。安全线任一不通过，故事直接打回，不进入画布和视频，不论笑点多好。
