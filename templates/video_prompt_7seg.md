> 再走 checklists/presubmit_audit.md 的提交前审计；审计不通过不提交。

## 拼装顺序（每段视频都按这个顺序写）

```
一句话写画风。整段的画风、颜色、人物设计与首帧和尾帧完全一致。
以主画布 M[×] 为准：人物、物品、场景、色卡全按主画布，不凭文字重发明。
整段 [X] 秒，[景别短码]，[机位短码]。
人和东西在画面哪里，墙和门是什么颜色；和首帧对得上；人物头或眼睛
落在画面横向约 38% 或 62% 处，不放正中间。
每个人的长相、衣服、固定道具，写死；固定道具的位置写清左右。
每件出场物品写“以主画布 I[×] 为准 + 物品 DNA 逐字 + 非此物清单”，
并写死人数与物品数量：“画面里一直只有 [N] 人，逐帧数人，无背景路人、无远处小人”；
“只有 [N] 只 [物品]”。
0–0.2 秒：画面完全静止，和首帧一模一样（快节奏段见动作版：开场即在动中）。
时空切片（v3.30）：10 秒切成 5 个节点，每 2 秒一节点，每节点强制绑定【画面 + 动作 + 运镜】，
不写一段笼统的长描述。节点之间是硬切的关键帧，不写“然后”“接着”。
节点 1（0–2 秒）：画面 [……]；动作 [……]；运镜 [……]。
节点 2（2–4 秒）：画面 [……]；动作 [……]；运镜 [……]。
节点 3（4–6 秒）：画面 [……]；动作 [……]；运镜 [……]。（5 秒处切镜 / 连续，写明在哪一秒、切还是连）
节点 4（6–8 秒）：画面 [……]；动作 [……]；运镜 [……]。
节点 5（8–10 秒）：画面 [……]；动作 [……]；运镜 [……]。
最后 0.3 秒：所有人完全停住，画面与尾帧完全一致（快节奏段见动作版：尾帧是动作进行中的一帧）。
只有看得见原因的声音。人物不说话。
画面里一直只有首帧这几个人和这些东西，脸和身形全程不变，一镜到底。
画面干干净净，没有文字、字幕、水印（画面内文字按 v3.3/v3.6 规则另行处理）。
物理参数（v3.30）：情绪词改写成物理参数，不写“很顺滑”“很震撼”“很美”；运动写物理规则
（例：ASMR 级顺滑物理运动）、光写物理规则（例：丁达尔体积光）、形变写物理规则
（例：纸质地图般的卷曲折叠）；对焦与景深写死（例：微距移轴 + 极浅景深，焦点锁在微观世界）。
质感反差（v3.30，微缩 / 微距 / 比例反差场景才用，产品广告全程适用）：写死两组对撞的质感（例：巨手皮肤毛孔纹理 ×
手工微缩模型的微瑕质感）、焦点锁定（微距移轴 + 极浅景深）、视觉闭环（例：玻璃罐封盖）。
质感反差对子按内容类型选，见 docs/PHYSICAL_PARAMETERS.md（产品 / 角色 / 动作 / 自然 / 食物 / 水 / 历史各有对子）。
限制（只写本集出过问题的项，宁多勿少）：脸和身形全程不变，皮肤质感与首帧一致，身体结构完整不穿模；[本集曾出过问题的项逐条列，正面说法优先]。
```

## 参考图：特写开场传局部裁剪（v3.31，见 docs/PRODUCT_AD.md）

- 切镜开场的第一参考图，默认传主画布；但**特写 / 微距开场（产品三摄、角色面部、物品细部、场景细部）**，
第一参考图改传目标局部的裁剪图（主画布上该部位格的裁剪，或主图的目标局部裁剪），整张主画布改作第二参考图。
- 根因：切镜开场传整张主图，模型会把主图当开场帧整个复用（构图锚定过强），新开场拍不出来；
传局部裁剪，模型才锚定到特写构图。MUSE 手机广告实测：三摄微距第一版因此失败，第二版传局部裁剪一次通过。
- 提示词里写死特写范围（“模组占满整帧、不拉回全景”“面部占满整帧、不拉回全身”）。

## 动作版（v3.20 新增：快节奏段专用）

快 tempo 的段不用上面头尾冻帧的写法，改写这两句：
- 开场：0–0.2 秒已在动中，不静止，第一个动作已经开始（例：剑已劈出一半、鬼爪已扑到面前）。
- 收尾：最后 0.3 秒是动作进行中的一帧，不停住（除非本段以定格收尾）；尾帧仍抽出来当下一段参考图，连续衔接不变。
- 逐秒里写速度词（骤然、猛地、瞬间、闪电般、残影），一镜 2–3 个连发动作写成箭头链（出剑 → 格挡 → 反击），每步写清在哪一秒。
- 中 / 慢节奏段仍用头尾冻帧的默认写法，不改。
- 时空切片照切：快节奏段也按 5 节点写，节点 1 即在动中（开场动作已开始），节点 5 收在动作进行中的一帧。

## 物理参数词库（v3.31：情绪词改写成物理参数，不写“很顺滑”“很震撼”“很美”）

> 完整库见 docs/PHYSICAL_PARAMETERS.md，按内容类型选参数（产品 / 微距、角色动画 / 儿童故事、
> 动作 / 打斗、自然 / 风景、食物 / 美食、水 / 流体、历史 / 建筑）。先定本段的内容类型，
> 再从对应类型里挑，不跨类型硬套。下面是各类的核心词，完整版以该文档为准。

- 运动：ASMR 级顺滑物理运动、匀速直线运动、自由落体、弹性回弹、惯性滑行、匀速推近、骤然加速、闪电般、残影、水流潺潺、蒸汽袅袅上升、云层缓移
- 光：丁达尔体积光、平行光束、漫反射、镜面反射、暖金逆光、冷调侧光、金色午后光、火光闪烁、水面反光、折射光斑
- 形变：纸质地图般的卷曲折叠、橡皮泥般的挤压回弹、布料般的垂坠摆动、金属般的弯曲不断、水面涟漪、面团拉伸回弹、旗帜飘动
- 对焦 / 景深：微距移轴、极浅景深、焦点锁死在微观世界、焦点锁在角色眼睛、焦点跟随动作、背景虚化、深景深
- 质感：毛毡哑光、黏土哑光、皮肤毛孔纹理、手工微缩微瑕、玻璃反光、金属拉丝、皮革纹理、陶瓷釉面、焦脆表面、水花晶莹、青砖粗糙
- 速度：每秒 X 厘米、0.5 秒内完成、骤然加速、匀速、戛然而止、缓慢、瞬间、闪电般

## 填表规则

- 是这模板的核心：每秒写谁做什么，不写“然后”“接着”这种空词；中 / 慢镜一个镜头只写
一两个主要动作，快镜可写 2–3 个连发动作（beats 字段写个数），动作太多才拆镜。写的时间只能算大概，多留一点时间，后期再用剪辑对节拍。
- 方向一律按画面写，不按故事写：“朝画面左边走，跨过左边的店门”，不写“往门口走”。
- 数量直接写死：“只有一封黄信封”，不写“一封信”。
- 原因先写再写动作：风做的事写风，不写人动手；手不该碰的东西写清“两只手从头到尾
没有碰它”。
- “不要……”的写法经常失效：能改成正面说法就改正面（“画面里一直只有首帧这几个人”，
不写“不要多出人”）；改不成正面的，干脆不让那个东西出现在有动作的镜头里。
- 动作要用到的东西，首帧里必须有；雨、帽子、纹身这类容易拍丢的东西，首帧和尾帧都要画上。
- 旁人反应要有先后：写清谁先、谁后（“老爸第一个……过一两秒老奶奶才……小女孩最后……”），
首帧也不要让几个人摆同一个姿势。
- 歧义句要写具体到位置：“左上角石头房子的窗口里”，再加一句排除（“驾驶座一直空着”）。
- 东西怎么动的要写清过程，不写结果：“顺着后脑勺往后一滑，接住，扣回头上”，不写“帽子飞走了又回来”。
- 镜头卡的 moving 和 move_reason 两字段填好再拼：这镜什么在动、运镜为什么动，
有一项是空的，说明这镜还没想好，重想。
- 限制清单（v3.29）：只写本集出过问题的项（穿模、变脸、磨皮、多出人等），宁多勿少；每项优先写成正面锁定（“脸和身形全程不变”不写“不要变脸”），写不成正面的才写明确禁令；没出过问题的不写，不堆通用禁令；本集出过的问题复发即先补进限制清单再重提。
- 真实感法则（v3.29）：动作里每个动词都要合物理——先写动作的物理前提再写动作（开灯先开玻璃门再点火，不能隔着玻璃点；风吹火要先撕破灯纸再让火摇晃熄灭）。写完逐个动词自问‘现实里能这样发生吗’，不能就重写。
- 时空切片（v3.30）：10 秒一段切 5 个节点，每 2 秒一节点，每节点强制绑定【画面 + 动作 + 运镜】，
不写一段笼统的长描述；段长不是 10 秒时按每 2 秒一节点切，节点数 = 段长 ÷ 2。节点之间是硬切的
关键帧，不写“然后”“接着”；切镜点（一段两镜时 5 秒处）落在节点内时，写明在该节点的哪一秒切，
前半段是前一镜尾、后半段是后一镜头；连续段的节点 1 画面 = 上一段尾帧，提示词首句仍写
`Continue from this exact frame.`。节点 1 的画面须等于首帧，节点 5 的画面须等于尾帧（快节奏段
节点 5 是动作进行中的一帧，仍须等于尾帧）。
- 物理参数（v3.30，v3.31 扩库）：情绪形容词（很顺滑、很震撼、很美、很高级）一律改写成物理参数，见上词库与
docs/PHYSICAL_PARAMETERS.md；**先定本段的内容类型（产品 / 微距、角色动画、动作、自然、食物、水、历史），
再从对应类型里挑参数，不跨类型硬套**；写完逐个形容词自问‘这是物理量吗’，不是就重写。运动、光、形变、对焦四类至少各写一条，
缺一类即提示词没写完。
- 质感反差（v3.30，v3.31 扩库）：只在微缩 / 微距 / 比例反差场景用（巨手与微缩模型、昆虫与叶片、模型与实景），
产品广告全程适用（玻璃 × 金属 × 哑光）；三要素缺一不可——对撞的两组质感（各写死纹理，见
docs/PHYSICAL_PARAMETERS.md 各类型的质感反差对子）、焦点锁定（微距移轴 + 极浅景深）、视觉闭环
（玻璃罐封盖、画框、镜头罩、镜面台面倒影等收束物）；普通场景（厨房、客厅、街道等无比例反差）不加，不硬套。
- 特写开场传局部裁剪（v3.31，见 docs/PRODUCT_AD.md）：特写 / 微距的切镜开场，第一参考图传目标局部的裁剪图
（主画布上该部位格的裁剪，或主图的目标局部裁剪），整张主画布改作第二参考图；提示词写死特写范围
（“模组占满整帧、不拉回全景”）。切镜开场传整张主图会把主图构图整个复用，新开场拍不出来。
