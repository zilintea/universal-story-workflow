# 七段式视频提示词模板（v3.7 新增）

> 来源：Eian 手册的七段式方法，按本仓库字段重写（见 docs/EIAN_HANDBOOK_REVIEW.md）。
> 替代 docs/SHOT_LANGUAGE.md 的旧 6 段拼装。每次生成视频前，先按镜头卡填好这七段，
> 再走 checklists/presubmit_audit.md 的提交前审计；审计不通过不提交。

## 拼装顺序（每段视频都按这个顺序写）

```
一句话写画风。整段的画风、颜色、人物设计与首帧和尾帧完全一致。
整段 [X] 秒，[景别短码]，[机位短码]，[运镜；不动就写“不推不拉不摇，不切镜”]。
人和东西在画面哪里，墙和门是什么颜色；和首帧对得上；人物头或眼睛
落在画面横向约 38% 或 62% 处，不放正中间。
每个人的长相、衣服、固定道具，写死；固定道具的位置写清左右。
0–0.2 秒：画面完全静止，和首帧一模一样。
[每一段：谁做什么，表情怎么变，手放在哪、不能碰什么，往画面哪边走]。
最后 0.3 秒：所有人完全停住，画面与尾帧完全一致。
只有看得见原因的声音。人物不说话。
画面里一直只有首帧这几个人和这些东西，脸和身形全程不变，一镜到底。
画面干干净净，没有文字、字幕、水印（画面内文字按 v3.3/v3.6 规则另行处理）。
```

## 填表规则

- 是这模板的核心：每秒写谁做什么，不写“然后”“接着”这种空词；一个镜头只写
一两个主要动作，动作太多就拆镜。写的时间只能算大概，多留一点时间，后期再用剪辑对节拍。
- 方向一律按画面写，不按故事写：“朝画面左边走，跨过左边的店门”，不写“往门口走”。
- 数量直接写死：“只有一封黄信封”，不写“一封信”。
- 原因先写再写动作：风做的事写风，不写人动手；手不该碰的东西写清“两只手从头到尾
没有碰它”。
- “不要……”的写法经常失效：能改成正面说法就改正面（“画面里一直只有首帧这几个人”，
不写“不要多出人”）；改不成正面的，干脆不让那个东西出现在有动作的镜头里。
- 动作要用到的东西，首帧里必须有；雨、帽子、纹身这类容易拍丢的东西，首帧和尾帧都要画上。
- 旁人反应要有先后：写清谁先、谁后（“老爸第一个……过一两秒老奶奶才……小女孩最后……”），
首帧也不要让几个人摆同一个姿势。
- 歧义句要写具体到位置：“左上角石头房子的窗口里”，再加一句排除（“驾驶座一直空着”）。
- 东西怎么动的要写清过程，不写结果：“顺着后脑勺往后一滑，接住，扣回头上”，不写“帽子飞走了又回来”。
- 镜头卡的 moving 和 move_reason 两字段填好再拼：这镜什么在动、运镜为什么动，
有一项是空的，说明这镜还没想好，重想。
