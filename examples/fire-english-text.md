# Fire! Run First! / 着火了，先跑！

## 一句话提示解析
- 原始一句话：发生了火灾
- IP：海陆空小队 / Sea-Land-Air Team
- 目标语言 / 难度 / 时长：英语 / 启蒙初级 / 文字 60–90 秒，视频 60 秒
- 生活场景：厨房火灾
- 警示点：Do not go back for things in a fire. / 着火了不回头拿东西。
- 主角（唯一）：Sesame / 白芝麻

## 学习目标
- 主题：When there is a fire, leave first, then shout for help. Do not go back. / 着火了，先离开，再求助，不回头。
- 关键词汇：**fire（/ˈfaɪər/，火）**、**smoke（/smoʊk/，烟）**、**run（/rʌn/，跑）**、**shout（/ʃaʊt/，喊）**、**safe（/seɪf/，安全）**
- 句型：Fire! Run! / 着火了，快跑！；Don't go back! / 别回去！

## 分幕剧本（英文对话和旁白，中文只在词汇表和教师备注里）

### Act 1: Smoke in the Kitchen / 厨房里冒烟了
- Narration: Sesame cooks soup in the kitchen hut. Smoke comes from the pot. More smoke comes. A towel near the stove catches fire. The fire grows. In the morning Magpie teaches Sesame one line. When there is a fire, run first, then shout.
- Dialogue: Sesame: “Fire!”

### Act 2: Run Out, Shout for Help / 跑出去，喊大家
- Narration: The smoke is bad. Sesame covers his mouth. He runs out. He shouts, “Fire! Run!” Magpie flies high. Magpie shouts, “Fire! Run!” Mung Bean, Ant and Persimmon run out. They run to the river bay. Sesame and friends shout for help.
- Dialogue: Sesame: “Run!” / Magpie: “Fire! Run!”
- Interaction: Pause and ask: Sesame runs out. What should he do first? Go back for things, or shout for help? / 跑出去了，他先该做什么？

### Act 3: The Scarf Stays, People Are Safe / 围巾不拿了，人最重要
- Narration: Sesame leaves his yellow scarf in the hut. He wants to run back. Friends shout, “Don't go back!” The fire is still in the hut. People are safe first. They count. One, two, three, four, five. All are safe. The fire grows small.
- Dialogue: Friends: “Don't go back!” / Sesame: “We are safe!”
- Interaction: Repeat with Sesame: “Fire! Run! Don't go back!”

## 词汇表
- fire（/ˈfaɪər/，火）：A towel catches fire.
- smoke（/smoʊk/，烟）：Smoke comes from the pot.
- run（/rʌn/，跑）：Run!
- shout（/ʃaʊt/，喊）：He shouts, “Fire! Run!”
- safe（/seɪf/，安全）：We are safe!

## 复习问题
1. What does Sesame do first when there is a fire? / 着火了，白芝麻先做了什么？
2. Does he go back for his scarf? Why not? / 围巾掉了，他回去拿了吗？为什么？
3. How do friends know all are safe? / 大家怎么知道一个都不少？
